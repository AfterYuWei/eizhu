# 账号、工作区与同步

账号负责服务器、分组、凭据和命令片段的多设备条目同步；完整版本及第三方云备份是独立能力，见 [云备份说明](BACKUP_CLOUD.md)。正式账号服务固定为 `https://eizhu.yuweinfo.com/`。本轮不接入官方备份或旧官方快照接口。

2026-10-27 已开始账号同步对接，当前为第一批「契约与空间基础」。具备运行时 schema、加密会话存储、独立账号空间、迁移副本及上下文切换校验；账号网络请求、登录界面、同步加密与调度尚未开放，公开请求仍返回 `STAGE_NOT_READY`，不产生虚拟登录态或同步成功结果。详见 [第一批交付记录](desktop-rebuild/ACCOUNT_SYNC_FOUNDATION_2026-10-27.md)。

现有服务端协议必须保持兼容，独立 `admin/` 不参与桌面实现。精确同步 v2、包装密钥、AAD/序列化/摘要及固定向量见 [兼容契约](desktop-rebuild/COMPATIBILITY.md)。

全局库升级为 schema v2，业务库升级为 v3。迁移前在新工程用户目录的 `schema-backups/` 创建一致性 SQLite 副本，包含已提交的 WAL 数据；旧离线空间的密钥派生和密文保持不变。回退旧应用需恢复升级前副本，不能让旧版直接打开新 schema。此升级只处理当前 Electron 工程数据，不查找旧应用数据。

账号空间由固定服务端身份和稳定用户 ID 的 SHA-256 标识，本地存储密钥按空间通过 HKDF 派生。令牌与本机解锁缓存使用设备密钥按用途加密；公开 DTO 不含令牌和密钥，冲突摘要拒绝凭据及未经筛选的 options。access token 过期仍可尝试刷新；刷新失效后保留账号身份与离线数据，进入 `reauth_required`。

以下为后续账号闭环与同步引擎的接入约束，不是已实现声明。

全局元数据与各工作区业务库分开，账号身份应包含服务端身份和稳定用户 ID。
每个请求/事件携带运行实例、空间及代次。main 绑定窗口与资源归属，业务进程再次验证；切换后旧确认和事件不得写入新空间。
业务变更、审计和加密 outbox 在同一数据库事务提交。本地成功即可返回；网络失败不能回滚本地编辑。
CAS、冻结幂等请求、响应丢失、SSE 重放、依赖冲突、离线编辑和重启恢复按原协议逐项验收。

账号切换先确认独立编辑器，再停止并等待旧空间任务和连接释放，随后切换代次。
新设备接入遵守既有初始化/合并流程，空库不得作为覆盖云端的依据。双客户端冲突和真实服务端故障恢复测试不可由单元 mock 取代。
