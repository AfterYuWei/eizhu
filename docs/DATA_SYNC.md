# 账号、工作区与同步

账号负责服务器、分组、凭据和命令片段的多设备条目同步；完整版本及第三方云备份独立管理，见 [备份说明](BACKUP_CLOUD.md)。正式服务固定为 `https://eizhu.yuweinfo.com/`。本轮不接入官方备份或旧官方快照。

前两批已提交为 `8cfa5e1`、`1168551`。第三批同步引擎的实现和执行证据见 [交付记录](desktop-rebuild/SYNC_ENGINE_2026-10-28.md)。真实后端账号、SMTP、双端部署和其他平台仍需第四批验收；合成协议通过不能替代这些项目。

登录进入独立账号空间，离线空间不自动搬移。同步数据密钥为随机 32 字节，Argon2id 包装、AES-GCM 加密，遵循 [固定兼容契约](desktop-rebuild/COMPATIBILITY.md)。修改同步密码只重新包装原密钥。登录密码找回不能解密云端；已有设备保留密钥时可设置新同步密码。

本机仅缓存受设备密钥保护的 DEK，不保存同步密码；退出删除本账号令牌和解锁缓存，业务库保留。刷新失败后保留账号空间身份和本地修改，要求重新登录。刷新轮换单飞并校验旧令牌，登录以数据库原子操作保留最新同步偏好和缓存。

首次接入需设置或解锁同步密码，再预览离线、账号本地与云端条目数量和冲突。默认勾选合并离线空间；确认前不上传，取消后仍保持登录。原离线库始终保留。token 绑定运行实例、空间、本地及离线修订、云端 seq/epoch；任一变化要求重新预览。

默认合并对同 ID、同内容去重，对不同内容保留冲突。离线副本冲突会明确标识来源；使用云端或使用本地前保存加密安全快照。使用本地必须包含全部远端身份及必要墓碑，以 expectedSeq 和下一 epoch 密文整体替换；超过 10000 条时明确拒绝，不拆分 replace。空本地库不会自动覆盖云端。

本地实体、审计、加密 outbox 同事务提交，保存不等待网络。每个账号仅一个同步循环；暂停仍积累修改。上传前持久化 requestId、精确请求体、密文及所覆盖修订。结果未知先查原请求；确认不存在才重发相同体。确认只删除对应本地修订，上传期间的新编辑保留。正常队列按本地修订组批；冲突及其关联依赖不上传。

首次使用固定水位分页快照；后续按 changes.after/until 分页。远端应用、影子修订、冲突及游标同事务提交，应用不产生回声 outbox。游标过期或 epoch 改变重新读取快照并核对待同步数据，不能直接覆盖本地编辑。依赖无法应用时保留有效本地图并持久化冲突；冲突选择前重新拉取并复核远端修订。摘要仅返回允许字段及敏感内容变化标记。

SSE 使用 main 的独立内存 Session、可取消的内部通道和逐块消费确认，单次最多 64 KiB、最多一块未确认；ready/change 仅唤醒增量拉取。断线按 1–60 秒退避重连，每 60 秒另行核对增量。暂停或空间关闭等待流结束，旧上下文消息失效。限流按等待时间重试；认证、配额、协议等永久错误停止自动提交并显示中文恢复入口。

有限 JSON 请求在 core/main 分别校验固定来源、方法、路径和数值，禁止 Cookie、重定向和管理员初始化写接口。认证与同步控制请求串行，写请求前关闭旧连接以防 Chromium 连接复用重发；SSE 单独连接，不被这些写请求打断。单条密文遵守服务端 2 MiB 字符上限，快照与有限请求各设 50 MiB 客户端处理上限；超限报错并保留本地数据。

全局 schema v2、业务 v3；本批不再升级 schema。迁移前的一致性副本位于用户目录 `schema-backups/`，包含已提交 WAL。旧版回退使用升级前副本，不能直接打开新 schema。离线密钥派生、旧备份格式和固定样本保持不变，不读取旧应用数据库。

账号切换统一由 main 确认编辑器、阻止新操作、关闭旧任务/网络/Worker，再切换代次；失败恢复原空间。UI 设置、历史、会话、任务、隧道、备份目标与 OAuth 令牌不属于条目同步。
