## 行为

- 上下文窗口移到默认收起的“高级设置”，提供8K、16K、32K、64K、128K、200K、256K、512K、1M、2M及自定义输入。K为1000、M为1000000 Token，自定义范围4096–2000000。既有96000等自定义容量直接恢复，不改写为预设。
- 模型目录按供应商保留。已保存供应商发现成功后，仅在地址、协议、密钥仍匹配时自动缓存模型目录，不保存草稿密钥、不停止Agent、不切换模型。新增供应商的目录随“保存并使用”保存。
- 重新打开设置或切换供应商仍可选择已发现模型；保留“自定义模型”输入。选定模型后点击“保存并使用”生效，停止旧运行、作废审批并完成现有摘要交接。上下文修改也由保存生效。
- 地址、协议或密钥变更清除旧目录；迟到的旧地址发现结果不能覆盖新配置，失败的发现请求保留旧目录。模型目录不参与连接测试/发现请求的输入传输。

## 数据与兼容

供应商DTO新增可选`models`字段，每项为`id/name`，最多1000项。既有配置缺少该字段视为空目录，保持已选模型、Key、启用状态和历史；无SQL迁移、无新增清理版本，不重复清理旧数据。`AgentRepository`沿用数据库Worker的加密`agent:v2:config`，目录不进入同步或备份。接口说明见 [AI_API](../AI_API.md)。
