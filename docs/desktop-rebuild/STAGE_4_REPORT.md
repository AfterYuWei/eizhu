| 范围 | 本轮实现 |
|---|---|
| 契约与 IPC | SFTP 输入、响应、会话、进度、任务和编辑器文本 schema；preload/main/runtime 校验；上下文和执行代次隔离 |

| 本机与远端 | 列表、隐藏文件、树、stat、新建、重命名、删除、移动、冲突策略；Windows 驱动器/UNC 路径转换；应用私有数据根及别名禁止从本机文件领域访问 |
| 文件传输 | 五路并发，最多 512 KiB 分块，逐块确认；本机/远端/跨会话 relay；同目录暂存、源与目标检查、校验后提交；100% 仅表示提交完成 |
| 目录与归档 | preserve 递归复制、tar.gz 流式压缩、ZIP 下载；重名目录整体重命名；文件/目录冲突、重复目标和自身复制保护 |
| 暂停与恢复 | 加密检查点由数据库 Worker 持久化；暂停/继续/取消/重试；重启标为 recoverable，手动恢复；源/暂存/目标变化拒绝拼接；原端点的主机密钥、路由、用户绑定 |
| 拖放 | 保留内部 Pointer Events；外部文件路径适配；文件/目录以原名称物化后交给 Electron 原生拖出；物化期间松开、Esc、失焦或失败会清理 |
| 编辑器 | 10 MiB UTF-8/二进制保护；保留语言、主题、换行与普通权限；mtime + SHA-256 冲突检查、三份比较和手动合并；暂存校验及原子替换，不支持时原文件保留并另存 |
| 窗口与所有权 | 延迟创建和打开队列；已授权文件路径/同目录另存；为编辑器保留文件会话，详情借用子通道在编辑器关闭释放；未保存确认及随机关闭请求编号 |
| 界面修复 | 刷新失联连接恢复原目录；列表/树响应绑定原标签及序列，避免切换标签后写错状态；SFTP MFA 轮询不重置输入；父目录行无时间时显示破折号 |

## 验证证据

- `npm run check`、`npm run lint`、`npm test`：46 项基础/契约/核心测试、205 项前端回归、10 项固定基线测试，共 261 项。
- `npm run baseline:verify`、`npm run architecture:verify`、`git diff --check`：固定证据只读、导入边界、旧入口清理和图标校验。
- 文件专项：相同 mtime 内容变化、权限和 CRLF、已有文件另存保护、非法 UTF-8/二进制/大小上限、符号链接、私有数据根及别名、归档、上传重复分块、重启手动续传、暂存篡改、并发十二个请求仍最多五路、目录重名、自身复制、排队源变化。
- Electron 主窗口 → preload → main → utilityProcess → 本机 OpenSSH `sftp-server`：真实 SFTP 列表/目录/重命名/删除、安全保存、分块上传暂停续传、2 MiB+17 字节下载和消费拉取、远端到本机 relay、目录归档；系统 tar/unzip 验证归档格式。SSH 外层为合成回环服务，不接入用户服务器。
- 不支持 posix-rename 的另一合成 SFTP 端点：覆盖明确拒绝，重新读取仍为原文件。
- 实际独立 Monaco 窗口：已打开文件可读，未授权路径拒绝；实际模型变更触发未保存状态；取消空间切换和原生窗口关闭保留内容，重放旧关闭请求拒绝。
- 实际 SFTP 双栏页面和完成队列截图；只浏览临时根。真实业务进程终止/重启后，从 SQLite 解密恢复的任务需手动选择原文件，按已确认偏移继续并提交。
- 同套烟测继续执行阶段 2 固定备份/反例、原生 SQLite/KDF/密钥及阶段 3 SSH/终端/隧道回归，并保留本地 Monaco worker、主题和进程恢复检查。

每个目录按文件提交，不能承诺整目录原子事务。ZIP 使用无压缩条目且上限 4 GiB，超过时选择目录传输或 tar.gz；本轮没有执行多 GiB 负载。恢复的源大小/mtime及确认前缀不能证明未确认部分从未发生同元数据修改。SFTP 不提供比较交换，最后检查与 rename 间的外部修改窗口无法彻底消除；OS 拖出后缺少复制完成回调，暂存保留到清理队列。远端离线时取消清理需要重连原端点，不报假成功。
