# AI 输入区与对话 Agent 选择

实现提交`82517ec`。本轮调整对话侧栏，当前接口规则见 [AI_API](../AI_API.md)。源码和证据仅本机提交，未推送、发布或部署。

## 行为

- 删除“内置助手 · 供应商 / 设置”重复栏，保留顶栏设置入口及独立的连接范围、操作权限。
- 输入区沿用项目中性色、圆角和共享菜单组件。底部依次放置附件菜单、Agent选择、模型选择和图标发送/停止；移除原“附加选区 / 附加文件”按钮。
- Agent列出已保存的供应商、登录后可用的官方模型入口，以及可执行文件、版本和必需参数检查通过的CLI。DeepSeek Harness还需原生模型和环境密钥；未安装或不兼容项不显示。业务进程在创建、切换和发送时再次检查，旧历史引用不可用CLI时禁止发送，要求用户显式选择。
- 模型选择使用供应商已保存的候选池，官方使用能力目录，CLI使用配置模型或原生默认。切换只作用于当前对话；设置默认值只用于新对话，恢复历史保留其后端。旧默认值不再覆盖所有已打开对话。
- 切换先停止旧运行、作废审批及旧授权，以摘要和近期记录交接，保留连接范围、草稿和附件。取消发生在CLI检查期间时，后到结果不能启动新运行。没有未知执行时，交接清除停止提示；未知结果提示保留。
- `+`菜单目前只提供上传附件：文本/JSON，最多8个、单个64KiB、合计128KiB。读取结束或失败均释放全部选择引用，失败不附加部分内容；可移除附件。菜单Esc只关闭菜单，保留侧栏。
- 未增加依赖、数据迁移或同步字段；配置与记录继续使用既有数据库Worker加密路径。
