# 模型候选池与上下文组合输入框

实现提交`beb3a5d`，未推送或发布。本报告更新此前模型目录自动缓存和双控件上下文的交互，以 [AI_API](../AI_API.md) 为当前接口说明。

## 行为

- 供应商的`models`数组改为用户维护的候选池。模型下拉框只列候选池，“管理候选模型”提供列表、删除、手动添加和自动发现。旧目录保留为初始候选，旧配置当前模型缺失时补入，保留已有选择。
- 自动发现只返回临时结果。用户选择某个结果后点击“加入候选池”，不会把探测结果整体覆盖进候选池。手动输入名称也加入同一个数组，按ID去重，不直接设置当前模型。
- 用户从候选池选择当前模型。删除当前候选后需重选；显式提交数组时，业务契约拒绝重复ID和池外模型。添加、删除、选择在“保存并使用”后生效，沿用停止运行、失效审批和模型摘要交接规则。
- 修改地址、协议和Key只清空临时探测结果，保留用户候选。发现不写配置、不停止Agent、不保存草稿Key。候选池仍由数据库Worker加密写入，不进入同步/备份，无SQL迁移或重复清理。
- 高级设置中上下文只有一个数值输入框。点击展开256K、512K、1M、2M，选择后仍可直接编辑该输入框。显示实际Token数，新配置256000，既有自定义值保留。支持上下箭头、Enter选择、Escape关闭，范围4096–2000000。
