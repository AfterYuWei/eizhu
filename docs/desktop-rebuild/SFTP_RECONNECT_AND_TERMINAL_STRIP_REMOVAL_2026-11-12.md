# SFTP 失效重连与终端提示条移除（2026-11-12）

## 行为

- SFTP 页面处理已有的会话状态事件。已连接会话失效时立即停止列表加载，显示“文件连接已失效，请重新连接”及“重新连接”按钮；另一侧和其他服务器标签独立保留。
- 目录路径只在读取成功后更新。失效、失败或迟到的旧请求不会覆盖最后成功浏览的目录；重连成功后直接读取该目录，不先跳转主目录。重连失败后再次尝试仍使用原目录，保留隐藏文件偏好和列表/树形视图，重建旧连接的树缓存。
- 失效后不自动重放文件写入或恢复传输任务。原目录无法读取时保留路径并显示错误。
- 按用户要求删除 SSH 右侧命令块提示条、对应设置开关、旧装饰生成和分块跟踪代码。OSC 边界处理继续服务于独立的日志关键词高亮；命令与普通输出沿用终端配色。
