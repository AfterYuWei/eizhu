启用的基础方法覆盖 bootstrap、平台/工作区快照、全局设置、窗口控制、关闭确认、系统对话框、剪贴板、有限本地日志及运行服务健康/恢复。领域方法必须先补齐运行时 schema 和资源归属规则，再开放实现；目前的领域 TypeScript 接口不构成功能完成声明。

## 进程与可靠性

主进程确认调用窗口、顶层 frame、可信 origin、权限及上下文；业务进程独立核对 `runtimeId`、`workspaceId` 和 `generation`。重启生成新的运行实例和代次，旧响应失效。事件按名称和载荷校验，订阅有数量上限及注销方法。

数据库 Worker 是 SQLite 的唯一访问入口，不向其他进程暴露 SQL。计算队列限制并发与等待数量；排队取消会释放容量，运行中取消等待完成后丢弃结果。关闭按明确所有权依次清理，挂起请求在进程退出时失败，不自动重放。

本轮补修了两处释放边界：候选业务进程启动后读取设置失败也要关闭；主进程收到关闭完成消息后仍须等待真实 `exit`，超时强杀后也不提前报成功。无法退出时保留窗口、恢复关闭状态并反馈错误，允许用户重试。相关纯生命周期函数新增专项测试，正常退出已通过最新 Electron 安装包烟测；强杀失败时的系统对话框仍未进行人工验收。

业务进程恢复前重新读取持久设置。主窗口与编辑器渲染进程保持存活；先前烟测验证了合成的编辑器内存标记仍在，**尚未证明真实远端文件的未保存标签完整恢复**。应用退出和工作区切换采用不同确认事件及请求 ID，拒绝过期或类型不符的确认。

窗口开启 sandbox、contextIsolation、webSecurity，关闭 nodeIntegration；本地协议检查路径，脚本、字体与 worker 不依赖 CDN。日志脱敏且有限额；密钥 Buffer 尽早清理，JavaScript 字符串及跨进程副本不具备可靠清零保证。

## 桌面外壳与 UI 差异

前端从 `web/` 移至 `apps/web/`，保留原桌面布局、共享 token、图标注册和组件；移除移动分支与旧容器调用。窗口拖动区改由 Electron 承载，保留桌面 Pointer Events、响应式布局和无障碍行为。

按冻结源码核对并修正：主窗口占工作区 85% 并居中；macOS 主窗口使用隐藏标题栏及原位置原生按钮；编辑器标题为“eizhu — 编辑器”，内容区域为 1280×800，macOS 编辑器采用标准原生标题栏。最新最终 DMG 烟测中的编辑器尺寸断言已通过，原生按钮的点击区、焦点与全屏仍需人工确认。
