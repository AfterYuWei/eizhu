# SSH 输入与输出颜色适配

2026-11-04 更新：命令输入改色与浅色输出变灰已删除，现使用右侧连续竖条标识整次命令及其输出，见[命令块标识验收](TERMINAL_COMMAND_BLOCKS_2026-11-04.md)。下文保留初版实现的历史记录。

日期：2026-11-01。本次验收限于本地开发构建，未打包发布或连接生产环境。

## 使用效果

在“设置 → 终端”新增两个独立开关：

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 命令输入高亮 | 开启 | 命令采用中性明暗区分：深色主题亮白、浅色主题近黑；浅色普通文本使用可读灰色，提交后保留命令强调色 |
| 日志关键词高亮 | 关闭 | 仅给默认颜色输出中的独立大写等级词补色：ERROR/FATAL 红色、WARN/WARNING 橙色、INFO 青色、DEBUG/TRACE 弱化色 |

开关即时生效，沿用现有设置持久化通道；关闭后恢复原有配色。保留远端 ANSI 前景色、背景、字形属性及选区显示。不增加输入/输出标签，不改变复制文本，不创建本地输入回显。日志规则不匹配 `ERROR_COUNT` 或小写 `error`。

更新后已有 SSH 会话需要重连一次以装载命令边界钩子；新建连接自动装载。此后切换高亮开关无需重连。

例如输入 `echo ERROR`，整条命令使用强调色；提交后的独立输出 `ERROR` 仅在日志开关开启时变红。`sudo` 密码继续无回显；程序内部交互不当作 Shell 命令。备用屏幕暂停增强，退出后恢复。

## 实现差异

- 扩展既有会话级 Shell 钩子，通过 OSC 133 A/B/C 标记提示符、命令和执行输出；续行提示符单独标记。不写入远端配置文件。Bash 4.4+ 使用 PS0，保留已有 PROMPT_COMMAND 字符串/数组；Zsh 保留既有提示符及钩子；Fish 在成功保留原提示符后包装并注册事件。
- 新增 xterm 渲染插件，只给默认前景色的可见单元格添加底层 Decoration。逻辑行锚点处理历史重排，物理锚点处理 xterm 暂不重排的正在编辑行，避免中文长提示符缩放错位。
- 标记随现有滚动缓冲淘汰；清屏、重连、销毁释放资源。输入文字不进入新的持久化或日志通道。
- 命令采用亮白/近黑的中性色。开启命令高亮时，浅色普通文本使用 `#686868`，与命令 `#171717` 拉开明暗差；关闭时恢复主题原正文色。深色正文及 ANSI 调色板不变。日志语义色取自已选终端主题，12 个预设主题均达到至少 4.5:1 的背景对比度。两个开关是内部 UI 偏好，不新增 IPC 方法或数据库迁移。
- 修复 ZLE 对长初始化命令插入重绘控制序列时的回显过滤。仅在比较时规范化，保留其他原始字节及真实错误信息。

## 验证证据

按用户选择，命令采用中性明暗区分：深色 `#FFFFFF`、浅色 `#171717`。进一步加强浅色普通文本与命令的差异，普通文本设为 `#686868`；全部浅色主题中，普通文本对背景保持至少 4.5:1 对比度，命令与普通文本之间至少 3:1。本次配色调整重跑终端与高亮回归 16 项（其中高亮 10 项）、Web 类型检查、相关 lint、固定基线及桌面构建，均通过。Electron/WebGL 另验证浅色灰度、关闭高亮恢复原主题及 ANSI 保留。下表的全量测试及完整桌面烟测是首次功能实现的证据，本次配色调整未重复完整烟测。
