# 同步冲突独立 Dialog 合并工作台

日期：2026-11-05。按用户选定的合并工作台方案实施到真实业务界面，不再仅提供交互 Demo；未提交或推送。

## 交付差异

- 云同步设置页移除逐条冲突卡片，只保留数量和“处理冲突”。服务器、分组或凭据上的冲突入口打开 Dialog 并定位条目。
- 独立 Dialog 包含冲突列表、字段对照和合并结果；逐字段选择、整条采用一侧、服务器保留双方副本、暂存、预览、统一应用。删除与恢复必须明确选择，关联条目可在 Dialog 中跳转。
- 暂存不写库，关闭后在当前设置页面与账号内保留选择；切换账号销毁旧工作台状态。相同字段折叠，中文名称优先展示，深浅主题与窄窗口使用共享语义色阶。
- 增加 `sync.resolveConflicts` 桌面领域方法。请求只携带条目身份、版本、选择及字段来源，不接受密码、私钥或原始连接配置。原单条方法保留既有调用兼容。
- 数据库 Worker 复核本机修订、远端修订与冲突来源；所选实体、引用图、审计、冲突移除和加密 outbox 同事务提交。关联不合法或事务中途失败时整批回滚。
- 凭据类型与凭据正文整组选择；服务器认证模式、凭据引用及内联/代理凭据同组选取。高级连接配置只提供来源选择，不向渲染端返回原始 options。
- 主机指纹继续保存在本机 SSH 信任记录中。指纹不进入同步差异和字段选择，已有远端协议序列化排除保持；选择云端内容不覆盖本机 SSH 信任记录。
- 暂停同步时处理冲突保持暂停；需要上传的结果进入本机队列。
