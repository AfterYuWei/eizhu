## 已确认的设计决策

| 项目 | 决定 |
|---|---|
| 产品 | eizhu 名称、图标、应用标识和中文桌面 UI 保持现状 |
| 前端 | 复用现有 React 桌面组件；尺寸、布局、颜色、入口、文案、快捷键和操作严格一致，允许字体抗锯齿差异 |
| 运行结构 | Electron 主进程 + 受限 preload + 独立 Node.js 业务进程 + 数据库/计算 Worker |
| 代码 | TypeScript 业务；允许成熟 Node 原生依赖；移除自有 Rust/Tauri 和移动端代码 |
| 仓库 | 原仓库重建，保留 Git 历史；不恢复此前已删除的 CLAUDE.md、CODEBUDDY.md |
| 数据 | 使用全新 eizhu-desktop 用户目录、独立开发目录和新 schema，不读取旧库、key、设置或任务 |
| 密钥 | 系统密钥库优先，首次初始化无安全密钥库时允许受限文件兜底；已有密钥失败不得重新生成 |
| 功能 | 完整保留桌面、本地、账号同步和云备份客户端能力；admin/ 保持独立闭源且不改架构 |
| 备份 | 继续导出 eizhu v1，读取 eizhu/XControl v1；不额外设计新格式 |
| 平台 | Windows x64，macOS arm64/x64，Linux x64；不扩展 Windows/Linux arm64 |
| 系统基线 | Windows 10/11、macOS 13+，Linux 验证 Ubuntu 22.04/24.04、Debian 12 和受支持 Fedora |
| 性能 | 20 连接、4 活跃终端、5 路传输，同时运行同步、指标和编辑器；初始 P95 交互门槛100ms、8小时混合稳定性验收 |
| 发布 | VERSION 为唯一版本源，保留 stable/test；首个 Electron 版本手动安装，使用独立更新源 |
| 签名 | 测试包先行；签名、公证和真实更新单独按平台验收，缺失项不能计为通过 |

## 检查与重采集

Node **24.7+** 才提供本轮独立验证所用的 Argon2 API；CI 使用 Node 24。本轮本机使用 Node 24.22.0。

```bash
npm run baseline:verify
npm run baseline:test
```

正常验证只读取冻结产物，不重新加密、生成密钥或更新摘要。历史源接口可以从固定 Git 提交重建，因此移除 Rust 源目录后仍可检查接口基线。CI 必须获取该历史提交，当前 frontend quality checkout 已使用完整历史。

旧样本采集工具已随原运行时退出；固定产物只读保存，历史采集步骤见阶段 0 报告。manifest 的 userApproved 是采集时字段，当前用户确认记录在本页，不修改冻结摘要。
