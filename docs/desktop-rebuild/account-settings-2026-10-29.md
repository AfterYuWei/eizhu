# 账号设置优化交付（2026-10-29）

## 本轮结果

1. 删除客户端云存储大小与配额展示。同步服务以服务器、密钥合计条数控制，每个用户默认最多 500 条，仅后台管理；分组、命令片段、已删除条目不计入。
2. 账号卡片展示头像、用户名及邮箱，保留“编辑资料”；移除“已登录”标签和“刷新账号”按钮，切换、退出收进“更多账号操作”。登录失效时直接提供“重新登录”。
3. 注册、修改、恢复主密码统一要求 8–128 位，包含大写字母、小写字母、数字和符号；现有账号登录不追加复杂度限制。账号弹窗统一标题、间距、输入框与底部按钮样式，保留提交锁定、错误回显及键盘操作。
4. 支持修改用户名、选择或移除头像。头像在客户端裁切压缩，经过领域接口交给服务端保存；用户名不参与登录，登录邮箱只读。主进程、运行时与数据库 Worker 继续按既有账号归属校验和持久化。
5. 资料通过已认证的 `/api/auth/me` 读取；注册、登录、刷新令牌响应的用户摘要保留既有字段，避免影响旧客户端的严格解析。令牌刷新保留本地已获取的资料。

## 差异范围

- `apps/web`：账号设置、资料编辑弹窗、账号身份显示、账号 API、主密码表单及样式。
- `packages/contracts`：资料输入输出、受限资料接口路由、新主密码校验。
- `packages/core`：资料读取、修改与账号会话持久化，条目限额错误翻译。
- 桌面验收：合成账号资料修改、头像上传、重启恢复、新密码策略及相应截图；同步测试密码适配新规则。
- 独立后台的资料接口、用户条目上限、管理页面及迁移独立保留，不加入桌面公共仓库。本报告只记录账号改动；同一工作区的连接、SFTP 等改动由其他工作负责。
