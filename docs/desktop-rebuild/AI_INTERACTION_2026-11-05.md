# AI 审批与结果展示调整

日期：2026-11-05。

## 行为

- 待确认命令显示在底部输入区，包含目的、目标服务器、目录、完整命令和影响。用户选择“允许执行”或“拒绝”，审批操作不再出现在聊天消息中。
- 审批结束后恢复输入框，保留原有草稿。审批区不再提供超时设置。断线或绑定的 SSH 会话变化时禁用旧审批，历史记录不恢复待确认操作。
- 当前 SSH 终端继续显示原始执行输出；聊天不再渲染 stdout/stderr，仅保留可展开的命令记录、执行状态、退出码和耗时。结果未知时保留核查提示，不提供重放按钮。
- 严格围绕用户指令执行。执行结果只用于判断任务是否结束或是否还需下一条命令；后续命令仍需逐条审批。执行后不再向聊天追加或流式推送解读、总结和建议，任务完成后直接结束；即使模型返回解读文本，也不会成为聊天消息。
- 同一轮连续的助手消息共用头像，普通文本回复保留复制等操作，命令执行记录不显示回复操作。通过 remark-gfm 修复 Markdown 表格解析，宽表格在侧栏内横向滚动；保留原有外链边界和远程图片限制。
- 保留逐条确认、当前终端执行、绑定校验和加密存储机制。
