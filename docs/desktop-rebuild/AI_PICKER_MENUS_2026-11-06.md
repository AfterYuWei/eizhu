# AI 供应商与模型菜单定位修复

## 当前交互：紧邻按钮展开，提示说明功能

按后续确认，菜单可进入输入卡片内部。现在直接在对应按钮上方留8px锚定间距，不再测量并避开整个输入卡片；当前供应商、模型选择及发送按钮仍保持可见。侧栏边界、240px宽度、限高滚动及长名称换行继续保留。

权限、供应商和模型统一使用共享Tooltip，内容分别为“切换操作权限”“切换供应商”“切换模型”。移除显示当前值的原生title，保留按钮中的当前选择和既有无障碍名称。同步更新已有Electron烟测的两处提示文案断言；该烟测本轮未执行。

本次类型、lint、30项侧栏定向测试、Web回归87文件1005项、固定兼容10项、基线与架构检查、Web构建通过。已安装Edge对真实组件配合假配置/会话验证16组菜单布局，以及320/400/560px、深浅主题下三种提示的18组悬停和聚焦交互。菜单不遮挡底部选择或发送按钮，不超出侧栏；关闭恢复焦点，切换模型保留草稿。新证据见[功能提示与菜单目录](evidence/ai-picker-actions-20261106/)。仅验证Web界面，未调用真实模型/SSH，未下载工具或重做安装包；临时服务、浏览器和测试profile已清理。

## 初版交付记录

原先两个菜单使用共享 Select 的选中项对齐方式：供应商名称折叠后定位偏移，可能横跨终端；模型菜单覆盖当前选择及输入区。本次仅为 AI 输入卡片改用按钮锚定的 Popper 定位，不改变设置页等其他 Select 的默认行为。

打开菜单时测量按钮到输入卡片顶部的距离，菜单在整个卡片上方留出间距；供应商靠按钮左端对齐，模型靠右端对齐。以实际 AI 侧栏为碰撞边界并保留8px内缩。菜单宽240px，最大高度320px且受可用空间约束，长名称换行，长列表在内部滚动；移除这两个菜单视口继承的按钮最小宽度，避免长模型名撑宽菜单。

验证：

- 类型、lint、30项侧栏定向测试通过。
- Web回归87文件1005项、固定兼容10项、基线及架构检查、Web构建通过。
- 已安装Edge以真实`AiInspector`组件及假配置/会话验证：320/400/560px侧栏、深浅主题，两种菜单共12组；另验证41个供应商、53个模型在700px及360px高视口下的4组长列表。
- 所有16组菜单均朝上、不与输入卡片相交、不超出侧栏、无横向溢出；长列表可滚动，矮视口自动减小高度。
- 键盘打开、Escape关闭及焦点返回按钮通过；切换模型后已输入草稿保留。页面无运行时异常及远程请求。
