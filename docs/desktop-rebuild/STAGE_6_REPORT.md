## 实现与差异

| 范围 | 最终行为 |
|---|---|
| 更新契约 | `update.check/download/install` 与进度事件先定义 schema，再由受限 preload/main 校验；仅主窗口可调用，复用 requestId/runtimeId/workspaceId/generation |
| 通道/目标 | stable/test 明确 HTTPS 基址，必须位于 `/electron/<channel>/`，追加平台/架构目录；不连接旧更新源；未配置时给出手动安装提示 |
| 候选与下载 | 随机候选令牌绑定已展示版本；下载期间拒绝重查替换，重查/运行实例重启使旧令牌失效；只接受目录内文件名与 SHA-512，下载失败拒绝安装 |
| 安装协调 | 禁止自动下载/退出安装；用户确认后才下载。安装前完成现有编辑器确认、退出备份和业务进程/Worker 释放；取消确认保留已校验缓存；安装器同步失败保留窗口并要求重启应用或手动安装，设备密钥仅最终退出清理 |
| 构建/打包 | 单一 VERSION 派生 stable/test 版本；main/React/安装包一致；构建记录包含来源提交、源码指纹、通道、架构和更新源，不匹配时拒绝打包 |
| 交付工具 | 流式计算安装包 SHA-256，核对包内版本/通道及全部构建文件字节，生成源码摘要清单；正确处理中文文件名与已删除文件 |
| 负载工具 | 完整 Electron 进程树内建立 20 个合成 SSH 会话、4 个活跃终端、每批 5 个本地传输任务及合成详情采样，记录 IPC 延迟和进程内存；可配置运行时长 |
| 代码整理 | 删除未引用 React/Vite 脚手架图标，移除无效旧目录 lint 排除；扩展架构审计覆盖现役构建/CI；无新增移动端或业务网关 |
| 文档/CI | 重写旧 CI/发布说明，校准架构/开发/补全/阶段索引，新增 39 项矩阵、清理审计、性能与发布清单；四目标候选工作流执行全回归和最终包 60 秒负载 |

UI 布局、颜色、窗口几何、品牌和键盘入口未调整。“关于”页面更新按钮由阶段占位错误切到真实领域方法；无更新源时显示明确失败说明，不假报已是最新。截图与自动化覆盖见 [证据索引](evidence/stage-6/README.md)。

## 验证与产物

最终执行结果、性能数值和包摘要以本报告后续的最终结果表及交付清单为准。静态检查与单测不能替代 Electron SQLite/KDF 原生验证，合成服务不能替代真实外部账号或目标平台。

本轮故障及修正：负载工具首次把五文件单任务误当五任务，改为并发提交五个独立任务；updater 隔离 AppAdapter 的默认网络执行器为空，烟测改为复用实际 Electron 执行器；交付工具改为 Git NUL 分隔处理中文路径。保留前两次 smoke 失败原始日志，均为工具验收阶段问题，最终结果单独采集。

## 平台与发布边界

| 目标/范围 | 本轮状态 |
|---|---|
| macOS x64 | 本机最终构建与 DMG 内容启动，详细结果见下方最终结果表 |
| macOS arm64、Windows x64、Linux x64 | 本轮未执行，待验；不借用阶段 1 的旧结果 |
| DMG/ZIP | 本地候选产物；DMG 只读挂载后复制至临时目录启动，不等同系统安装/覆盖安装/Gatekeeper 验收 |
| 系统密钥库、原生 IME/TUI/拖放/窗口交互 | 回归与合成覆盖按所属报告记录；真实系统人工矩阵待验 |
| 外部 SSH/MFA/Agent、云厂商 OAuth/账号 | 合成协议与令牌保护有测试，真实服务待验 |
| 独立源与签名升级 | 客户端和 shared downloader 真实 HTTP/摘要拒绝已接通；无已部署源或证书，真实签名升级未执行 |
| 性能 | 本机短时合成负载；IPC P95 不等于交互 P95；真实五路网络、备份/编辑器混合及 8 小时稳定性待验 |
| 官方账号/同步/官方备份 | 按用户要求延期，不属于本轮已实现功能 |
