# 账号同步第三批：同步引擎

日期：2026-10-28。第二批已按用户要求提交为 `1168551`，未推送。第三批接通账号条目同步；真实部署与双端验收留给第四批。本批不接入官方备份，不修改独立后台。

## 实现与差异

| 部分 | 结果 |
|---|---|
| 密钥 | 计算 Worker 执行 Argon2id、随机 32 字节 DEK、AES-GCM 包装与条目加解密；沿用固定 user/type/id/revision/epoch/deleted AAD，密码按 UTF-8 原字节处理 |
| 记住解锁 | 数据库 Worker 用设备密钥保护缓存 DEK；不保存同步密码。退出清除缓存，普通会话失效保留缓存与本地数据；密码轮换仅重新包装原 DEK |
| 登录并发 | 登录会话在数据库中原子合并，保留最新同步偏好和解锁缓存；刷新 CAS 继续保留并发更新的字段 |
| 首次接入 | 默认预览离线、账号本地、云端数量和安全冲突摘要；取消保持登录且不上传。token 绑定空间/运行实例、本地与离线修订、云端 seq/epoch |
| 合并 | 同 ID 同内容去重，不同内容保留冲突；离线副本明确标注来源。原离线库保留，替换前保存加密安全快照 |
| 整体替换 | 完整集合和必要墓碑、expectedSeq、下一 epoch 密文一起冻结；超出服务端 10000 条上限明确拒绝，不拆分 replace。空库不自动覆盖云端 |
| 上传 | 每账号一个同步循环；本地提交不等网络，暂停继续积累 outbox。上传前保存精确请求体、requestId、密文与覆盖修订；未知结果先查原请求，确认不存在后才重发同一体 |
| 确认 | 验证请求身份、条目及 seq/epoch；只清理被冻结请求覆盖的修订，上传中的新编辑保留 |
| 拉取 | 固定水位分页快照与 changes.after/until；远端业务、审计、影子修订、冲突和游标同事务，远端应用不生成 outbox |
| 恢复 | 游标过期或 epoch 变化重新取得快照并核对本地待同步内容；不直接覆盖待同步修改 |
| 冲突 | 选择前拉取并复核远端修订；保持分组、凭据引用及跳板图有效，无法应用的关联条目持久化为依赖冲突。摘要不包含凭据正文或原始 options |
| 通知 | main 独立内存 Session 执行 SSE；内部通道逐块确认，最多一块 64 KiB 未确认。ready/change 只唤醒增量拉取，1–60 秒重连，60 秒定时核对兜底 |
| 界面 | 紧凑中文设置页：同步开关、密码、首次预览、待同步数量、最近确认、冲突和中文恢复入口。远端应用刷新服务器、分组、凭据和片段视图 |

只同步四类条目及关联关系。UI 偏好、历史、会话、传输、隧道、备份目标和 OAuth 令牌不进入同步。令牌、DEK 和解密后的凭据正文不进入普通 React/Zustand 状态。

本批继续使用全局 v2 / 业务 v3，没有新的 schema 升级；第一批的迁移前一致性副本和离线密钥派生保持。固定备份和协议样本未修改。回退旧版仍须使用升级前副本，不能打开新 schema。

两个隔离目录用例已通过：

- 固定 Rust 包装、普通条目及墓碑向量；错误密码与身份篡改拒绝；并发首次包装 CAS 得到同一 DEK。
- 首次确认前零上传；默认合并保留原离线库；第二端快照应用没有回声 outbox。
- 冻结后继续编辑，旧确认保留新修订；提交响应丢失后重启先查询；提交前丢失则逐字节重发相同请求体。
- 固定水位分页、并发编辑、删除冲突及远端修订复核；本地未决内容保留。
- 非法关联删除保留有效图并持久化冲突，重启后仍存在，后续合法修改可恢复。
- 游标过期、epoch 变化时保留本地待同步；修改同步密码重包装原 DEK，新端可用新密码解锁。
- 离线或账号本地修订改变使预览失效；整体替换使用完整集合、预期水位和下一 epoch；10001 条替换明确拒绝。
- SQLite 触发器在远端审计写入时故意失败，业务、影子、冲突和游标一起回滚。

完整桌面链路已通过：密码表单解锁、取消预览、确认后自动出队、首次接入与开关状态一致、伪高水位通知不能推进游标或确认时间、单条 SSE 连接及断线重连、暂停释放 SSE 并保留新 outbox、恢复继续上传、HTTP 提交响应丢失只写一次且查询恢复、运行进程重启记住解锁、退出清除缓存、原离线数据保留。SSH/SFTP/编辑器、本地与第三方备份、更新烟测同时回归。
