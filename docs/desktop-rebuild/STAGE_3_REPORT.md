## 验证证据

- `npm run check`、`npm run lint`、`npm test`：33 项基础/契约/SSH 测试、201 项前端回归、10 项固定基线测试，共 244 项。
- `npm run baseline:verify`、`npm run architecture:verify` 和 `git diff --check`：固定样本只读、旧架构/移动入口缺失、Node/Electron 导入边界及原图标摘要校验。
- Electron 合成 SSH 服务：真实密码、加密 Ed25519 私钥及交互认证握手；错误指纹/已消费确认拒绝；永久信任后后续连接；HTTP CONNECT、SOCKS5 和跳板。
- preload → main → utilityProcess：刻意跨帧切断中文字节及 emoji、256 KiB 突发输出/消费确认、终端尺寸、固定补全/引号路径、目录特殊文件名、服务器信息和合成资源指标。
- 三类真实回环隧道连接/回显、停止后端口拒绝连接；本地隧道断线后自动重新监听；终端重连不重放输入。额外注入主机指纹拒绝/取消、MFA 取消、握手中停止、HTTP 407、端口占用及 SOCKS5 半包/32 并发上限，核对拒绝前未发生认证及关闭后旧回答失效。
- Electron 数据库 Worker：501 条保留至 500 条、重复计数、关闭记录、31 天过期清理、关闭重开持久化、SQLite 无合成历史/凭据/信任/隧道正文、备份不含历史、隧道引用阻止服务器删除。
- 保留阶段 2 固定备份/反例、SQLite 故障回滚、OpenSSH 密钥、进程异常恢复、Monaco、本地状态及明暗界面烟测。

早期烟测捕获并修复 Ed25519 导出格式不被 ssh2 重解析、手动目录读取的 EOF 处理、等待远端 channel close 导致的停止超时，以及跨输出帧重置 UTF-8 解码器的问题。早期失败不计为通过；最终结果只引用最终构建/安装包的证据。
