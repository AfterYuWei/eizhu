# AI 设置页面整理

按本轮反馈，将使用方式和配置集中到设置页。实现提交 `62f7ae7`，未推送或部署。

- 增加“启用AI助手”开关。关闭后停止模型/CLI及关联任务、作废审批，禁止新对话和推理；配置、密钥和历史继续加密保存。
- “使用方式”下拉框选择内置助手、Codex、Claude Code或DeepSeek Harness。仅显示当前选项的配置。
- 内置助手通过“模型来源”下拉框选择官方AI、已保存供应商或新增供应商；只呈现当前供应商的协议、地址、Key与模型。发现、测试和保存仍分开。
- 对话侧栏显示当前设置和设置入口，移除重复的Agent选择器。设置切换会先停止旧任务，再为已打开对话保存摘要交接；恢复旧对话也沿用当前设置。
- 使用设置页现有的标签说明、右侧控件、共享Select/Switch和响应式布局，修复原来全部配置平铺、字段缺少行式布局的问题。
- 新空间默认关闭；已有新版配置没有开关字段时保持原启用行为，无需清空配置或历史。
