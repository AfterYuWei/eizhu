# 阶段 6 性能与稳定性记录

2026-10-21，当前主机 macOS x64（Darwin 25.6.0），Electron 44.9.0 / Node 24.22.0。构建输出与最终 DMG 都运行完整隔离进程树；原始结果见 [构建报告](evidence/stage-6/mac-x64-build-smoke.json) 和 [最终包报告](evidence/stage-6/mac-x64-package-smoke.json)。

本轮是短时合成负载。**完整混合性能门禁尚未通过**：没有执行真实五路远端网络、完整备份/编辑器同时运行的交互计时或 8 小时稳定性。官方账号同步按用户要求延期，不能将占位状态加入负载后宣称通过。

## 实测结果

| 指标 | 构建输出 | 最终 DMG |
|---|---:|---:|
| 负载要求时长 | 3 秒 | 60 秒 |
| 实际负载时长 | 3.074 秒 | 60.057 秒 |
| SSH 会话 / 活跃终端 | 20 / 4 | 20 / 4 |
| 每批独立本地传输任务 | 5 | 5 |
| 完成批次 | 35 | 731 |
| IPC 测量样本 | 120 | 2422 |
| IPC P50 | 0.300 ms | 0.300 ms |
| IPC P95 | 0.400 ms | 0.400 ms |
| IPC 最大值 | 0.600 ms | 2.000 ms |
| 烟测首次窗口可见 | 694.2 ms | 710.1 ms |

每批任务复制五个 2 MiB 本地合成文件；任务状态逐批等待完成，结束后逐字节核对五个目标文件。20 个 SSH 会话使用本机合成握手/回显服务，四个会话通过二进制 MessagePort 持续输入和消费输出。详情采样使用合成服务器输出；传输走本地端点，不能算作五路真实 SFTP 网络吞吐。

IPC 计时是在渲染进程内对 `window.state()` 调用测量 round trip，包含 preload/main 契约校验；不包含输入到画面呈现的时延，所以不能用此 P95 判定“交互≤100ms”。首次窗口数据也不是受控冷启动基准。未并行运行另一个桌面 smoke；普通桌面环境和后台任务仍可能影响结果。

## 最终包进程内存采样

取 `app.getAppMetrics()` 的进程 working set 求和，单位换算为 MiB；不等同长期峰值或泄漏证明。

| 负载时间 | working set 合计 | 进程数 |
|---|---:|---:|
| 0.009 秒 | 623.1 MiB | 5 |
| 30.008 秒 | 702.9 MiB | 5 |
| 60.004 秒 | 733.1 MiB | 5 |

采样数量和时长不足以判断资源长期有界。进程重启、编辑器内存保留、持久任务恢复、端口释放、Worker 有界队列和慢终端消费分别由完整 smoke 与回归检查；这些检查不替代 8 小时验收。

## 重跑与正式验收

先 `npm run desktop:build`。`npm run desktop:stress` 默认 60 秒；追加 `--duration=28800000` 可运行 8 小时合成负载。最终安装包可执行 `npm run desktop:smoke:package -- <安装包路径> --duration=60000`。脚本记录完整进程树结果和截图；保留原始日志、主机环境及相应安装包摘要。

正式验收还需在四目标与支持系统上，使用真实网络、五路流式传输、可见四终端、完整备份、详情和编辑器混合负载，记录交互延迟分布、吞吐、CPU/内存/句柄/端口及 8 小时后的资源回落。未执行项保持待验；失败要保留日志，不能刷新固定兼容样本消除差异。
