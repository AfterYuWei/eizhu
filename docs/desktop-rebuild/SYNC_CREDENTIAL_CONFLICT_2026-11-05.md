# 同步凭据冲突展示与删除文字

## 交付内容

- 删除冲突中的删除状态、选择文字、合并结果和确认预览使用危险色。
- 凭据对比展示具体变化项：凭据类型、认证方式、关联凭据、密码、私钥、公钥、私钥口令、代理密码。双方卡片展示类型、设置状态、已有密钥指纹及条目修改时间；修改时间不作为自动取舍依据。
- 用户点击“查看双方凭据”后才读取并并排显示双方正文。隐藏、切换条目、进入结果预览或关闭窗口时卸载查看组件；忽略迟到响应。普通冲突摘要和结果预览不包含正文，前端仍只提交字段来源。
- 新增受限只读方法 `sync.revealConflictCredentials`，沿用主窗口与空间上下文校验，要求同步已解锁，并核对条目身份、本机修订、远端修订和云端/离线来源。冲突已变化或已解决时拒绝读取，不调用远端网络或修改业务数据。
- 按字段比较凭据内容，避免对象属性顺序不同被误判为凭据变化。
