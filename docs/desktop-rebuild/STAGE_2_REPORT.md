## 安全与故障边界

main 只向主窗口开放本地业务。preload、main、runtime 与数据库 Worker 校验已启用方法；原窗口/frame/origin/上下文验证继续生效。SSH、账号、同步和云目标保持 `STAGE_NOT_READY`，不会返回空数据伪装完成。

系统选择器返回随机授权引用，绑定窗口 ID、runtimeId、workspaceId、generation、用途和 15 分钟期限，最多 64 个。渲染端传入任意路径或其他窗口/代次的引用不能读文件。计算 Worker 实际打开文件后校验文件身份、大小和修改时间，读取期间变化也拒绝；备份内容不会返回 React。保存先写同目录临时文件，写完后才替换目标。

预览正文通过设备密钥加密保存在业务库，最多 4 份、15 分钟有效。普通导入重新读取已授权文件并比对预览摘要；应用核对本地业务修订。运行服务重启后旧 token 不能直接应用。取消预览不修改业务数据；恢复失败不会留下部分实体、审计、outbox、安全快照或已消费的预览。

设备主密钥经 HKDF 分离空间密钥，AES-256-GCM 的 AAD 绑定数据用途、实体类型/ID及 outbox 修订。已有数据密钥错误时拒绝启动，不重新生成。审计只记录操作、记录标识和时间，不保存正文。敏感剪贴板的条件清理由 main 持有，关闭表单或渲染窗口不会取消计时；系统权限失败不导致应用退出。

## 验证证据

`npm test`：25 项基础/契约/安全测试、201 项前端回归、10 项固定基线测试，共 236 项。类型、lint、固定字节校验、架构校验与差异空白检查另行执行，记录见本目录 `evidence/stage-2/`。

Electron 原生集成在 utilityProcess 下的隔离数据库 Worker 实际运行：

- 七份固定旧备份：eizhu/XControl 三模式及历史 Go 空密文；精确 payload 字节、中文及 emoji、真实加密 OpenSSH 私钥、代理密码、未知 options 与关联。
- 十份固定反例：预览和直接导入使用生产 codec，核对冻结错误码并确认完整原数据未变。
- 真实 SQLite 触发器在 outbox 写入中途故意失败，验证业务、审计、outbox、安全快照及预览消费全部回滚。
- 冲突三策略、完整 merge/replace、关联重映射、预览过期与期间本地编辑拒绝、安全快照恢复。
- 生产导出/解码往返；加密前 payload SHA-256；密码首尾空白不被 trim；超过 50 MiB 拒绝。
- ED25519/RSA2048/RSA4096、OpenSSH 口令与公钥注释、错误口令拒绝。
- SQLite 不含合成凭据明文；正确密钥关闭重开后持久化；错误密钥拒绝并保留数据。

真实 preload → main → utilityProcess → Worker 链路另验凭据创建/查看、生成密钥、引用保护、列表脱敏、审计及业务进程重启后的服务器持久化。保留编辑器、Monaco 语言 Worker、窗口隔离和进程恢复烟测。

原生集成测试不在普通 Node 进程加载 SQLite/KDF，也不修改固定样本。最终证据见 [交付清单与产物摘要](evidence/stage-2/delivery.json)、[第一次最终 DMG 烟测](evidence/stage-2/mac-x64-package-smoke-first.json)、[复跑](evidence/stage-2/mac-x64-package-smoke.json)及[证据索引](evidence/stage-2/README.md)。测试包在 `artifacts/desktop/stage-2/`，未签名、公证或发布。

早期两次包烟测超时不计为通过，定位输出将复现范围缩到业务检查完成后的截图阶段。烟测改为仅对合成测试窗口关闭后台帧节流，有界等待真实绘制，并禁用截图时的过渡动画、核对明暗实际像素；正常产品窗口的后台策略未改。最终同一 DMG 连续两次完成全部检查，明暗侧栏亮度分别为 244/24。原失败日志保留，未将窗口遮挡时的帧等待误报为业务功能已失败或已通过。

## 界面差异与人工验收

- 原服务器、凭据和片段组件接通本地方法；未实现的连接操作仍提示阶段未就绪。
- 备份页新增“完整恢复与安全快照”，使用既有 AlertDialog 和共享样式，展示来源、新增/变更/相同/替换移除计数。确认失败保留预览；提交成功后刷新失败提示“已恢复”。
- 文件导出取消不再提示下载成功；成功提示“备份文件已保存”。完整版本/自动备份/云端目标显示阶段 5 提示。
- 日志页新增“本地审计”，用中文操作名显示，不包含凭据正文；日志大小文案纠正为当前 256 KiB。
- 有子分组时删除父分组会拒绝并给出引用，不自动拆散层级；私钥格式/口令/公钥不匹配会明确拒绝。
- 主窗口尺寸、侧栏、主题、字体、快捷键及图标布局未重新设计。新增恢复流程仍需人工检查焦点、键盘和窗口缩放。
