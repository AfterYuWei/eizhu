# 数据备份精简交付（2026-11-01）

按用户要求，数据备份只保留自动备份与文件导入导出；已配置的第三方云目标继续接收新备份，既有云端数据不处理。

## 功能与实现

- 设置页只保留“自动备份”和“文件导入与导出”。移除版本列表、版本保留数、版本恢复、完整恢复、安全快照、备份事件及相应 IPC/DTO/API。
- 自动备份由主进程选择本地目录，计算 Worker 生成密码加密的 `.eizhubackup` v1 文件，经临时文件写入、刷盘和原子重命名后保存；文件名包含时间及随机 ID，不覆盖已有文件。
- 保留变更防抖、间隔/每日调度、正常退出备份，以及“立即备份”触发。没有启用的云目标时只写本地；有目标时并发有界地上传同一个新文件，读回校验仅针对刚上传的对象。
- 保留 WebDAV、S3、Google Drive、OneDrive 配置与 OAuth。上传失败展示本地文件已保存；上传结果未知不自动重放；Electron 云备份网络沿用独立会话及新写入连接，排队执行以避免 Chromium 在复用连接丢失响应后自动重发。既有云端文件和索引不读取、修改或删除。
- 导入导出继续兼容 `.eizhubackup` / `.xcbackup`、三种凭据模式、固定旧格式及中文密码。保留文件预览、skip/overwrite/regenerate、关联 ID 重映射、预览失效与事务回滚。

## 数据库

- 业务 SQLite 升至 schema v4；迁移由数据库 Worker 执行，迁移前在 `schema-backups/` 生成一致性副本。
- 删除 `safety_snapshots` 表、旧恢复预览及 `archive:*` 中的备份正文、版本目录、序列、事件、旧同步标记；保留备份密码、云目标凭据与身份。设置改为自动备份调度参数；数据库只保存配置和最近一次备份结果，备份正文保存在所选目录。
- 业务实体、账号会话、同步表、outbox、审计、命令历史、任务及侧栏偏好保留。账号/条目同步的修订与幂等机制继续使用，不属于被删除的备份版本管理。
- 升级后需要先选择本地目录，再启用自动备份；原有间隔/每日时间/防抖参数保留。清理逻辑只作用于打开的工作空间，其他空间在各自首次打开时升级。
- 一致性迁移副本用于回滚，不属于产品中的备份版本功能。当前会话只在临时隔离数据库执行验收，未手动清理用户日常数据目录或连接真实云账号。
