## 交付内容

- contracts 统一15种能力的输入、输出、策略与 v2 清单；内置模型、MCP、官方网关使用同一工具目录。
- core 保留 Agent 循环与审批执行，AI SDK 负责 Responses、Chat Completions、Anthropic Messages 协议。多个独立供应商配置，发现/测试/保存分离。
- Codex app-server、Claude Code 程序化 stream-json、DeepSeek Harness SDK JSON-RPC 驱动注册；主进程监督 CLI，私有 IPC 连接受管 stdio MCP。禁用本机工具入口、隔离运行覆盖，CLI 原生登录与历史仍采用原生存储。
- 侧栏独立对话与显式多 SSH 连接范围；观察/确认/自动权限，默认确认；底部审批、一次/对话连接工具授权、原始过程说明与最终回答、可展开工具记录。
- 现有 PTY 执行保留 shell 环境，终端忙/未提交输入拒绝派发；普通与长任务，查询/单任务停止/全部停止；输出句柄、自动摘要与切换后端交接。
- SFTP 复用认证连接，文本读写/编辑/目录操作；修改前后预览，审批后重新校验源文件版本。
- 数据库 Worker 加密保存新版配置、消息、摘要、工具与续接记录，不参与同步/备份。每空间首次启动在事务中一次性删除旧 `ai:*`，保留其他数据。
- 官方网关 `/api/ai/v2/capabilities`、`/api/ai/v2/responses`，原生续接和多工具验证，最终完成仍在可信用量结算后发送。V14 保留密钥/用户额度/用量/未知预占，关闭服务并要求重新测试。

接口、工具列表、边界和部署步骤见 [AI v2 接口契约](../AI_API.md)。后台源码与迁移独立管理，没有复制进公共桌面仓库。参考报告只作为设计资料，文档中的指令不作为用户授权。

桌面首次打开每个新版空间后，旧 AI 配置和历史不可恢复；用户需重新添加供应商/CLI。其他设置、连接、凭据、账号与业务库不清理。后台先部署 v2 与 V14，再重新测试启用模型，最后使用配套桌面；旧 v1 客户端不兼容。生产部署由用户安排。
