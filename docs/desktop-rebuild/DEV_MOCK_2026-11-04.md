# make dev 本机 Mock 数据

日期：2026-11-04。

`make dev` 显式设置 `EIZHU_DEV_MOCK=1`，启动本机账号和同步协议模拟器。Mock 仅允许未打包应用和 `http://127.0.0.1` 开发渲染地址；与烟测模式互斥。发布版保留固定生产地址，未增加任意后端配置。

每次启动创建新的 `eizhu-dev-mock-*` 临时数据目录，数据库、设备密钥及 Chromium 数据相互隔离；原 `eizhu-desktop-dev` 和正式应用的数据不修改。退出应用不删除用户原有目录。重启 `make dev` 重建初始 Mock 集合，不续跑上次测试结果。原始、无 Mock 的开发入口仍为 `npm run desktop:dev`。

启动后已登录合成账号，自动同步暂停。账号标记为“Mock 测试账号（本机模拟）”；合成登录信息在 `apps/desktop/src/main/dev-mock-data.ts` 的 `devMockLogin` 中，仅供本机模拟器使用。模拟邮件验证码为 `123456`，不会发送邮件。

## 数据集

- 账号空间：7 台服务器、2 个分组、1 个凭据及命令片段。
- 离线空间：3 台服务器，退出账号后可查看。
- 6 项已持久化冲突：分组名称、凭据内容、服务器字段与改名、云端删除、本机删除及命令片段内容。
- 同名、同地址、不同 ID 的服务器保留为两条数据，不列为冲突。
- 主机指纹不同的示例不列为冲突；云端序列化不包含主机指纹。
- 单侧存在的服务器正常保留；初始待同步数为 8，冲突数为 6。

所有条目带有 `【MOCK】` 前缀，地址使用文档示例地址段，不应连接真实服务器。数据通过数据库 Worker 的既有导入与同步事务写入；KDF 和条目加密在计算 Worker 执行。未增加渲染端 SQL、文件系统或模拟数据写入接口。
