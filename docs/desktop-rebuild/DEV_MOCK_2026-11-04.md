# 合并工作台局部 Mock

更新日期：2026-11-05。本次范围替代原先整套账号、服务器及同步协议模拟环境。

`make dev` 仍设置 `EIZHU_DEV_MOCK=1`，但该变量只用于开发渲染器里的合并工作台预览入口。进入设置 → 云同步，点击“预览合并工作台（Mock）”；无需登录模拟账号。

## 隔离范围

- 示例只存在于独立弹窗的组件状态，不写入共享 Zustand store、数据库、Chromium 存储或文件，也不调用 IPC 或网络。
- 工作台显示 6 项示例冲突，可选择字段、查看合成凭据、暂存及“模拟应用”。模拟应用只移除当前弹窗内已选的示例；关闭弹窗丢弃示例状态，重新打开恢复初始集合。
- 服务器侧栏、密钥管理、命令片段、账号身份、待同步数、冲突数和真实同步流程沿用原有开发数据及服务。真实“处理冲突”入口仍读取和处理真实冲突，不被示例替换。
- 删除主进程的全局 Mock 启动分支及其种子数据。`make dev` 与 `npm run desktop:dev` 使用同一个正常开发数据目录 `eizhu-desktop-dev`，设备密钥保护保持正常策略，不再注册模拟账号、导入示例或替换账号服务。
- 预览入口仅在开发模式且显式设置开关时出现。生产构建不包含此入口及数据；原有 `--smoke-test` 隔离验收环境保留。

旧 `eizhu-dev-mock-*` 临时目录不再使用；不读取、迁移或删除其中的数据。正式应用和用户数据不处理。

## 验证

- 定向回归覆盖 mock 凭据查看、6 项选择与模拟应用、关闭再打开重置，以及整个过程不触发桌面桥接、网络、持久化或共享状态变化。
- 开发入口回归覆盖未登录时独立打开预览，原账号身份和真实同步状态保持不变，关闭预览不清除真实冲突焦点。
- 原有真实工作台的逐字段选择、暂存回看、预览应用、失效选择拒绝、凭据查看清理及跨账号状态隔离回归保留。
- `npm run check`、`npm run lint`、`npm test`、`npm run baseline:verify` 通过：基础测试 214 通过、2 项 Fish 测试跳过；Web 87 文件、960 测试通过；固定格式基线 10 测试通过。
- 设置 `EIZHU_DEV_MOCK=1` 执行生产构建通过；检查桌面构建输出，未包含局部预览入口、示例密码或已删除的全局种子模块。
- 旧全局 Mock 开发窗口已正常退出；未启动真实账号服务进行生产验收。
- 本机未签名 DMG/ZIP 打包通过，带 `EIZHU_DEV_MOCK=1` 运行最终安装包完整烟测通过（macOS x64），确认该开关不会启用模拟账号环境。测试后已注销并删除项目 `.app` 副本，保留正式应用和用户数据。记录见 [验证摘要](evidence/merge-mock-isolation-20261105/validation.json)。其他平台及签名、公证未执行。
