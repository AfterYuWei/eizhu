# AI 运维助手交付与验收

日期：2026-11-01。桌面客户端已接通；官方网关由独立后端按 [接口契约](../AI_API.md) 实现并部署，本轮未访问生产、未推送或发布。

## 使用与界面差异

连接服务器后，在顶部工具栏打开“AI 助手”。右侧面板与服务器详情互斥，默认 400px，可在 320–560px 间调整，窄窗口使用浮层。设置新增“AI 助手”，可选择官方 AI 或自配 Chat Completions / Responses 模型；自配配置支持加密保存密钥、清除密钥和测试工具调用。

输入需求后，AI 提出一条命令，卡片展示目标、目录、目的和影响。点击“执行此命令”才会调用独立 SSH exec；执行结果自动回传分析，下一条仍需确认。默认超时 60 秒，可在确认前调整到 1–600 秒。首版仅支持非交互 POSIX shell，免密 sudo 使用 `sudo -n`；密码输入、TTY 和持续交互请在现有终端处理。

默认只发送当前连接的基本信息、已缓存系统信息和目录，不读取终端历史或凭据库。用户可手动附加终端选区或本机文本文件，并预览、移除。最多 8 个附件，合计 128 KiB；单个文本文件读取上限 64 KiB。

每个标签保留独立活动对话，历史按空间和服务器归档；断开连接后仍能查看和删除历史。当前空间最多 100 个对话，每个最多 200 条消息、8 MiB 存储，达到上限时提示新建或删除，不静默清理。历史、配置和密钥不参与账号同步或备份。

## 进程、存储与失效规则

- 沿用 renderer → preload → main → utilityProcess → 数据库 Worker。AgentService 属于现有业务进程，core 不依赖 Electron，未新增框架或依赖。
- main 只接受主窗口 AI 领域方法，并绑定实际窗口 ID。业务进程保存命令提议、工作目录和 SSH 连接实例；确认接口只接受提议 ID 与决定。确认先同步消费授权、保存执行中检查点，再发出 SSH 请求。
- 拒绝、模型切换、显式断开/重连和运行实例变化使旧提议失效。即使自动重连后 session ID 相同，也必须匹配原连接实例才能执行。重启恢复的执行中记录显示结果未知，未执行记录失效，不恢复授权。
- 模型网络最多 4 个独立会话槽，每个请求只允许一块不超过 64 KiB 的未确认跨进程数据；新连接避免复用连接导致模型 POST 重放。流式 UI 更新只发送当前消息，不反复广播整段历史。
- SSH stdout/stderr 合计最多保留 256 KiB，超过后继续消费并标记截断。回传模型时 stdout 取首尾各 16 Ki 字符，stderr 最多 8 Ki 字符；模型请求另受 512 KiB 限制。
- 停止和超时尽力发送 TERM 并关闭通道；没有退出码就显示结果未知，不承诺远端进程已停止或已经回滚。新命令永远不会自动执行。
- 数据库 Worker 复用现有 `local_state`，分别加密配置、索引和对话。schema 保持 v4，不产生业务实体、同步 outbox 或备份字段。密钥读取只返回存在状态；已知密钥和令牌、私钥块及常见敏感字段在模型上下文中脱敏。
