## 当前界面

- CPU、内存、硬盘、网络上下行和“服务器信息”各自独立。默认 14px 界面使用 11px、400 字重与中性色，数值不再使用更重的颜色或字重。
- 五项均使用共享图标注册表：CPU、内存条、硬盘、网络和服务器。移除原来的圆形信息图标与聚合详情入口。
- 鼠标悬浮约 300ms 或键盘聚焦后，只显示该项详情；支持移入浮层、Escape 关闭和逐项加载/错误反馈。删除点击展开全部指标及信息页签的交互。

- CPU 显示总使用率、分核与频率；内存显示容量和占用较高的进程；硬盘显示根目录及挂载点容量；网络显示上下行与各网卡速率；服务器信息显示当前连接、系统、内核、架构、运行时间及负载。
- 数值使用等宽数字并预留固定区域：底栏百分比和上下行速率组、详情中的数字与单位列、容量对、CPU 分核/频率、进程占用及平均负载均保持位置稳定。数值位数或单位变化不推动相邻项目。
- 底栏“网络”文字与速率保留间隔；下载速率靠右、上传速率靠左，上下行内容之间保持 8px 间距，预留空间分布在两侧。两组仍各占固定宽度，数值位数变化不移动相邻项目。详情浮层继续保留数值和单位列对齐。
- SFTP 独立保留文件管理和目录状态；窄内容区允许摘要换行，浮层不改变终端或文件区尺寸。

## 前后端重构

- 用 `serverDetail.getSummary({ sessionId })` 和 `getMetricDetail({ sessionId, kind })` 替代旧整包 `getMetrics`，补齐领域 DTO、判别联合及运行时输入/输出 schema。
- 常驻摘要每三秒只读取 CPU 总值、内存/根目录使用率和网络速率，不枚举进程、分核或全部挂载点。只有当前悬浮项目才执行对应的固定 SSH exec，并在悬浮期间每三秒刷新；服务器信息按同样方式调用 `getInfo`。
- 前端直接绑定当前终端 SSH 会话，不再将指标放入 SFTP 的服务器级目录缓存；不同终端和空间的结果隔离。移除旧指标 DTO、就绪状态、WebSocket 命名状态和聚合更新方法。
- 离开项目或隐藏窗口后停止对应刷新；关闭、断线、切换终端和空间后，旧响应不能覆盖当前内容。同一会话快速移开再移回会复用在途只读查询。
- 查询失败只影响对应摘要或悬浮内容，不再把指标错误标记为 SFTP 断开。网络速率按实际采样间隔换算；进程名称和挂载点可包含空格。
- 后端继续验证 SSH 会话及连接实例，并使用有界 exec 和既有远端查询并发限制；选择器只能是四种固定枚举，不接受任意命令。
