日期：2026-10-27。用户已确认第一批并授权提交、进入账号闭环；本记录随第一批代码提交，未推送或发布。本文不是完整账号同步上线声明；证据中的未提交工作区状态指验证执行时的状态。

## 实际交付与差异

| 部分 | 本批结果 |
|---|---|
| 产品边界 | 账号负责服务器/分组/凭据/片段同步；完整版本与第三方备份独立。本轮不接官方备份或旧官方快照 |
| 契约 | 账号/同步公开方法、同步 v2 wire DTO、脱敏事件的运行时 schema；安全整数、六位验证码、注册/重置密码 UTF-8 长度检查 |
| 会话状态 | 区分匿名、有效会话、需要重新登录。access token 过期仍允许刷新；失效状态保留账号身份 |
| 前端适配 | 适配 sessionState 与 includeOffline；冲突摘要限定安全字段。退出与状态查询均失败时保留真实展示，不伪造退出成功 |
| 全局存储 | schema v1→v2；设备密钥保护账号会话、活动空间和本机同步数据密钥缓存；不保存同步密码 |
| 业务存储 | schema v2→v3；增加同步状态、远端影子、冻结请求、冲突与预览的存储表及 outbox 索引 |
| 空间隔离 | 固定服务端身份＋稳定用户 ID 派生账号空间标识；按空间派生本地存储密钥，离线密文派生保持原样 |
| 迁移保护 | 原密钥预检；SQLite 一致性副本包含已提交 WAL，重试生成新副本并保留已有副本；失败不留下半迁移业务 schema |
| 进程 | 数据库 Worker 读取活动空间；main/runtime 启动握手核对身份。替换候选失败后等待实际关闭，再用新代次恢复原空间 |
| 上下文 | 为登录/注册/退出准备专用切换响应校验；preload 拒绝延迟旧上下文及不匹配的切换结果 |

账号和同步的 schema **尚未加入公开操作启用表**。真实登录、网络刷新、邮件、同步密码学、首次接入、CAS/幂等调度、SSE、冲突持久化与处理属于后续批次。本批新增的同步存储表不代表同步引擎已经实现。

没有修改 VERSION、依赖、锁文件、品牌、固定兼容样本或独立后台源码；没有创建真实账号或写入部署后端。
