# SFTP、传输与独立编辑器

阶段 4 沿用双栏、多标签、树、传输队列、Pointer Events 拖动与独立 Monaco 编辑器，接入 Electron 文件领域。实际平台证据见 [阶段 4 报告](desktop-rebuild/STAGE_4_REPORT.md)。

## 接口与资源

`packages/contracts/src/sftp.ts` 为启用的方法、响应与事件提供运行时 schema。preload、main、业务进程再次验证；事件绑定运行实例、空间和代次。仅主窗口可以管理文件会话、目录与传输。编辑器只能读取已打开路径，或在该文件同目录另存为新文件；不会收到通用 fs、SQL 或执行入口。

`packages/core/src/sftp/` 拥有文件适配、目录枚举、调度、归档和文本保存。认证、最多五级跳板、代理、指纹及 MFA 复用阶段 3，文件会话独立拥有连接链。未知或变化指纹必须确认，随机请求在关闭、重连和取消后失效。Windows 驱动器显示为 `/C:/...`，UNC 为 `/UNC/server/share/...`，远端保持 POSIX 路径。

目录最多 10000 项，树深度最多 6；递归传输最多 10000 项/64 层。修改、文本读取和传输拒绝符号链接路径、设备、管道和套接字。类型冲突和重复目标不会用成功结果掩盖。
本机文件会话排除应用私有数据根及其别名，不能借文件管理器读取设备密钥、业务库或内部检查点。烟测只由主进程向隔离运行实例注入临时文件根，不访问用户目录。

## 流式传输与恢复

最多五路传输。浏览器文件使用最多 512 KiB 原始字节块，逐块等待远端写入和数据库确认；本机/远端/跨会话文件直接在 Node 中读写，保持分块与背压，不经过 Base64。下载在私有目录暂存，完成后通过系统保存对话框导出，或按消费拉取字节块。

目录支持保留结构或 `.tar.gz`；多项/目录下载生成 ZIP。归档逐文件流式生成，ZIP 使用标准无压缩条目，tar.gz 使用流式 gzip。ask/overwrite/rename/skip 在开始前检查，rename 对重名目录整体改名。目录按文件提交，已经完成的文件保留，不承诺整个目录的一次原子事务。

当前界面使用 `sftp.transfer` 的 `background: true`，先取得持久任务，再在后台扫描、检查目标和传输。下载及系统拖出准备同样先创建任务。队列区分扫描、打包、传输、检查及提交，显示项目数量和当前文件，扫描期间可暂停或取消。未知总量不显示确定百分比。后台冲突会暂停原任务，通过 `sftp.getTransferConflicts` 查询、`sftp.resolveTransferConflicts` 选择处理方式，不重新创建整个传输请求。

文件先写同目录随机暂存，等待协议写入与关闭确认，检查源元数据、暂存类型/长度及目标快照后提交；正常完成不全量回读目标文件，内容哈希用于断点恢复。覆盖要求 OpenSSH posix-rename；不支持时保留原目标并报错。最终提交后才显示 100%。

数据库 Worker 将检查点加密写入空间本地状态，不进入备份或同步 outbox。记录源/目标身份、确认偏移、SHA-256、序列和执行代次。暂停保留检查点；取消等待句柄关闭后清理暂存。远端失联时需要重新连接原端点完成远端清理，不报假成功。重启恢复为 recoverable，需手动连接匹配的主机密钥、路由和用户后继续。

完整目录计划与增量游标分开加密持久化，进度更新不再重复序列化整份目录清单，兼容旧完整检查点。当前空间共用一个轮询补偿事件，不因超过十分钟停止跟踪。目录重新开始保留已提交文件，仅重传未完成部分；详见 [2026-10-26 文件夹传输报告](desktop-rebuild/SFTP_DIRECTORY_REWORK_2026-10-26.md)。

上传恢复重新选择原文件，比较大小、mtime 和第一块哈希，并核对远端暂存哈希；其他复制继续时比较源的已确认前缀。源中未确认部分若被改为同大小、同 mtime，仍可能无法检测。源、暂存或目标变化会拒绝拼接/提交；重新开始不隐式同意覆盖变化后的目标。

内部拖动保留现有复制/移动及冲突弹层；系统拖入使用受限 webUtils 文件路径。拖出先物化具有原名称的文件/目录，main 仅接受完成任务的编号。物化期间松开、Esc、失焦或失败会清理任务与暂存。交给系统后的文件保留到清理已完成队列；Electron 没有可靠的外部复制完成回调，不在系统可能仍复制时提前删除。

## 安全保存与关闭

文本读取限制 10 MiB，拒绝二进制和非法 UTF-8；保存按 UTF-8 字节再次检查大小，保留权限与 LF/CRLF。打开时、当前编辑和最新远端三份内容交给比较/手动合并界面。保存比较 mtime 与 SHA-256，同目录暂存、校验，在提交前再次检查；缺少安全替换能力时另存。SFTP 没有服务端比较交换原语，最后一次检查与 rename 间的外部修改窗口无法彻底消除。

编辑器延迟创建，未就绪打开请求排队。main 为编辑器保留已打开 SFTP 会话；服务器详情借用的子通道在编辑器关闭时释放。关标签、关窗口、退出和空间切换先处理全部未保存内容；原生关闭与切换确认携带随机请求编号，旧回答不能用于新请求。进程退出或代次变化保留编辑内容并阻止旧授权写入。

本轮真实系统拖放、其他平台、远端供应商/网络故障、签名、公证和长期压力的执行范围按交付报告标注，不由接口存在或 CI 配置推定通过。
