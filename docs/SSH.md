# SSH、终端与隧道

阶段 3 使用 `ssh2`，连接位于 Electron utilityProcess 的 `packages/core/src/ssh/`，不建立本地 HTTP/WebSocket 网关。前端继续使用原 xterm、分屏、搜索、片段和补全组件。SFTP 文件操作与编辑器保存见 [阶段 4 报告](desktop-rebuild/STAGE_4_REPORT.md)；阶段 3 的详情文件树只开放有界目录读取。

## 认证与路由

数据库 Worker 只向业务进程返回所选路由及其凭据。支持密码、内联或凭据库私钥、系统 Agent、keyboard-interactive，以及直连、HTTP CONNECT、SOCKS5 和最多五级跳板。代理域名通过目标代理/SSH 服务器解析。OpenSSH 私钥的口令解密及 Ed25519 重封装在有界计算 Worker 执行，不阻塞终端事件循环。

每一跳独立校验 SHA-256 主机指纹。未知和变化指纹都暂停握手，提供一次信任、永久信任与拒绝。确认绑定随机请求、连接、指纹及运行实例；关闭、重连、超时后旧确认失效。永久信任通过数据库 Worker 加密保存。测试连接不隐式接受新指纹，需要先通过终端明确确认；不会保存临时测试表单。

交互认证提示与回答有数量、长度和超时上限，取消时结束连接链。认证回答不会写入命令历史。Buffer 尽快清理；JavaScript 字符串及第三方库内部对象不能承诺可靠清零。Agent 使用 macOS/Linux 的 `SSH_AUTH_SOCK` 或 Windows Pageant，实际 Agent 集成列入目标平台人工验收。

## 终端与生命周期

preload → main 控制请求验证主窗口、顶层 frame、本地 origin、运行实例、空间和代次。订阅使用独立随机标识；main 验证会话后通过 `MessageChannelMain` 把业务进程的二进制输出端交给受限 preload。渲染页面无法取得原始 IPC 或 MessagePort。

输出约 16 ms / 32 KiB 批处理，最多 64 KiB 在途；preload 等待 xterm 的写入回调完成后才确认累计字节。慢消费者让 SSH readable 暂停。重放最多 1 MiB，超过缓存会明确显示缺口提示；重新订阅只提供输出与当前状态，不重放输入。UTF-8 解码跨二进制帧保持状态，OSC7 工作目录由业务进程有界解析。

输入、尺寸、固定补全生成器和远端 ping 仍使用受限异步控制请求。输入队列有界，断开期间拒绝写入。断网启动指数退避，最多十次；远端正常退出终端后等待用户手动连接。关闭与重连先取消指纹/MFA、关闭流和整条路由，再开始新连接；不依赖 React 卸载。

补全只接受注册生成器和结构化参数。路径通过 SFTP 子通道读取，支持中文、空格、引号及主目录；目录最多 10,000 项/约 2 MiB 元数据，返回候选最多 4,096。其余生成器使用后端固定模板及 shell 参数引用，不接受前端脚本。每会话并发、输出、时限、缓存数量和有效期有界；旧连接结果不会进入重连后的候选。

## 本地历史与详情

只有前端能够核对普通终端缓冲区回显的单行输入才提交历史，TUI、不可靠输入及前导空白不记录；记录不表示执行成功。历史按空间/服务器加密，默认 500 条/30 天，可关闭记录和清理。启动、设置变更、读取和每小时巡检执行保留策略。历史、主机信任和隧道不进入交换备份或同步 outbox。

服务器详情取得当前已连接终端的只读引用，按请求创建并释放 exec/SFTP 子通道；关闭详情引用不关闭终端。原页面只在详情可见且应用位于前台时每三秒采样，隐藏和切换后丢弃旧结果。Linux `/proc` 采集脚本沿用固定历史源；不支持的远端明确报错，不用零指标冒充成功。

## 端口映射

本地、远端与动态 SOCKS5 隧道各自建立 SSH 路由，复用同一认证/指纹策略。配置加密保存在当前空间，应用重启后等待手动启动。监听默认使用 `127.0.0.1`、`::1` 或 `localhost`，也可选择 `0.0.0.0` / `::` 对外监听；端口 0 自动分配。动态模式仅支持 TCP CONNECT，域名在远端解析。

每个隧道最多 32 个活动或握手中连接，握手有界；流式 pipe 保持背压和半关闭。断网释放已有转发，按指数退避最多十次重新建立监听，不重放数据。状态带代次及递增修订，停止/启动/保存/删除按隧道串行；停止同时释放本地监听与 SSH 连接，远端释放等待 unforward 或底层连接关闭。端口占用、远端拒绝等错误提供中文失败状态。

本轮实际测试和剩余目标见 [阶段 3 报告](desktop-rebuild/STAGE_3_REPORT.md)。

### 使用方式

左侧“端口映射”、终端更多菜单和 `Ctrl/Cmd+Shift+L` 打开同一个工作区工具标签。重复打开不会创建新标签；关闭标签返回此前终端，没有终端则返回连接首页，映射继续运行。

1. 点击“新增映射”，填写名称并选择现有 SSH 服务器。服务器选项读取当前空间完整列表，不受侧栏搜索或分组筛选影响。
2. 选择本地映射、远端映射或动态代理。默认选择回环监听；需要其他设备访问时选择 `0.0.0.0` 或 `::`。监听端口填写 0 可自动分配。
3. 本地映射的目标由 SSH 服务器访问；远端映射的目标由本机访问。两种情况下目标 `127.0.0.1` 所指机器不同，表单和列表均标明位置。动态代理不填写目标，仅支持 SOCKS5 TCP CONNECT，域名由服务器解析。

   目标主机可填写公网或内网 IPv4、IPv6、域名，是否可达取决于上述发起连接的一端。目标地址不受监听地址枚举限制，也不会自动改变监听范围；仅目标使用公网地址时不触发对外监听确认。IPv6 直接填写地址，不带方括号；端口在目标端口字段填写。

   表单按方向标注“本机监听 / 远端目标”与“服务器监听 / 本机侧目标”。三种模式分别保留本次表单的地址草稿，切换时不会沿用另一模式的监听和目标；切回可恢复该模式的输入，只保存当前选中的模式。远端映射可在“服务器监听地址”选择 `0.0.0.0` / `::`，和本地映射的“本机监听地址”一样支持对外监听。目标主机可下拉选择 `127.0.0.1`、`::1`、`localhost`，也可直接输入具体 IP 或域名；`0.0.0.0` 不是目标地址。

   右侧动画随模式和输入展示映射流向：本地映射从本机到远端目标，远端映射从服务器到本机侧目标，SOCKS5 从服务器分流到客户端指定的目标。预览仅表示当前配置，实际运行状态以规则列表为准。窄窗口将预览放在表单下方；系统启用减少动态效果时显示静态路径。
4. 保存配置后点击“启动”。复制监听地址使用启动后的实际端口，IPv6 使用 `[::1]:端口`。运行中表示 SSH 和监听已经建立，不对目标服务执行定时健康检查。
5. 停止后才能编辑。删除前确认，后端先停止监听和现有连接，成功后才移除配置。

关闭终端、导航到其他页面、关闭端口映射标签均不停止映射；退出应用、切换账号空间或业务进程退出会释放映射，应用重启后需手动启动。配置继续保存在当前空间原有加密 `tunnels` 状态中，不做数据库迁移，不进入同步或交换备份。

### 本机 OpenSSH 验证

macOS/Linux 已安装 `/usr/sbin/sshd` 和 `/usr/bin/ssh-keygen` 时，可执行 `npm run desktop:smoke:tunnels`。脚本使用临时配置、临时密钥，SSH 服务只监听回环；映射覆盖回环和临时全地址监听，只转发测试回显服务。不修改系统 SSH 配置，结束时停止测试服务、释放端口并删除临时密钥。覆盖三种模式 × 五种监听地址 × 固定/自动端口，共 30 组收发和释放检查；对外监听在存在相应本机非回环网卡地址时通过该地址自连，不将此视为外部公网验收。结果写入 `artifacts/port-mapping/<平台>-<架构>-openssh.json`。

该脚本验证生产转发器与真实 OpenSSH 的协议互通；Electron 窗口、IPC、数据库和认证生命周期另由 `npm run desktop:smoke` 验证，两类证据不能互相替代。

### 对外监听与二次提醒

选择 `0.0.0.0` / `::` 时，表单首先提醒该端口可能被局域网或公网访问；每次手动点击“启动”还会弹出“确认对外开放此映射？”，展示规则、SSH 服务器地址、监听端口和目标。取消不会建连或占用端口，确认后才启动。SOCKS5 没有客户端认证，对外开放会明确提示可能成为任何人可用的代理。

后端要求 `tunnel.start({ id, confirmedConfig })` 的确认快照与当前保存配置一致；缺少确认返回 `TUNNEL_PUBLIC_CONFIRM_REQUIRED`，配置变化返回 `TUNNEL_CONFIG_CHANGED`。前端在配置变化时重新读取列表并保留错误，不自动重试启动。启动授权不进入数据库；停止后再次启动、应用重启或切换空间后均需重新确认。同一次已确认运行的断线重连保持原规则，不逐次弹窗。

全地址监听不等于获得公网 IP，也不表示防火墙或 NAT 已放行。客户端应使用设备的实际 IP/域名连接，不能使用 `0.0.0.0` 或 `::` 作为对外访问地址。应用不修改路由器、防火墙或 SSH 服务端设置。

远端映射还受 SSH 服务端的转发策略控制。建议由服务器管理员配置 `GatewayPorts clientspecified`，使服务端按用户选择的地址绑定；默认 `no` 会限制到回环，`yes` 则强制使用通配地址。监听成功不能证明外部公网可达。参见 [OpenSSH 官方 sshd_config 手册](https://man.openbsd.org/sshd_config#GatewayPorts)。
