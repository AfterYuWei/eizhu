# SSH、终端与隧道

阶段 3 使用 `ssh2`，连接位于 Electron utilityProcess 的 `packages/core/src/ssh/`，不建立本地 HTTP/WebSocket 网关。前端继续使用原 xterm、分屏、搜索、片段和补全组件。SFTP 文件操作与编辑器保存仍属于阶段 4；阶段 3 的详情文件树只开放有界目录读取。

## 认证与路由

数据库 Worker 只向业务进程返回所选路由及其凭据。支持密码、内联或凭据库私钥、系统 Agent、keyboard-interactive，以及直连、HTTP CONNECT、SOCKS5 和最多五级跳板。代理域名通过目标代理/SSH 服务器解析。OpenSSH 私钥的口令解密及 Ed25519 重封装在有界计算 Worker 执行，不阻塞终端事件循环。

每一跳独立校验 SHA-256 主机指纹。未知和变化指纹都暂停握手，提供一次信任、永久信任与拒绝。确认绑定随机请求、连接、指纹及运行实例；关闭、重连、超时后旧确认失效。永久信任通过数据库 Worker 加密保存。测试连接不隐式接受新指纹，需要先通过终端明确确认；不会保存临时测试表单。

交互认证提示与回答有数量、长度和超时上限，取消时结束连接链。认证回答不会写入命令历史。Buffer 尽快清理；JavaScript 字符串及第三方库内部对象不能承诺可靠清零。Agent 使用 macOS/Linux 的 `SSH_AUTH_SOCK` 或 Windows Pageant，实际 Agent 集成列入目标平台人工验收。

## 终端与生命周期

preload → main 控制请求验证主窗口、顶层 frame、本地 origin、运行实例、空间和代次。订阅使用独立随机标识；main 验证会话后通过 `MessageChannelMain` 把业务进程的二进制输出端交给受限 preload。渲染页面无法取得原始 IPC 或 MessagePort。

输出约 16 ms / 32 KiB 批处理，最多 64 KiB 在途；preload 等待 xterm 的写入回调完成后才确认累计字节。慢消费者让 SSH readable 暂停。重放最多 1 MiB，超过缓存会明确显示缺口提示；重新订阅只提供输出与当前状态，不重放输入。UTF-8 解码跨二进制帧保持状态，OSC7 工作目录由业务进程有界解析。

输入、尺寸、固定补全生成器和远端 ping 仍使用受限异步控制请求。输入队列有界，断开期间拒绝写入。断网启动指数退避，最多十次；远端正常退出终端后等待用户手动连接。关闭与重连先取消指纹/MFA、关闭流和整条路由，再开始新连接；不依赖 React 卸载。

补全只接受注册生成器和结构化参数。路径通过 SFTP 子通道读取，支持中文、空格、引号及主目录；目录最多 10,000 项/约 2 MiB 元数据，返回候选最多 4,096。其余生成器使用后端固定模板及 shell 参数引用，不接受前端脚本。每会话并发、输出、时限、缓存数量和有效期有界；旧连接结果不会进入重连后的候选。

## 本地历史与详情

只有前端能够核对普通终端缓冲区回显的单行输入才提交历史，TUI、不可靠输入及前导空白不记录；记录不表示执行成功。历史按空间/服务器加密，默认 500 条/30 天，可关闭记录和清理。启动、设置变更、读取和每小时巡检执行保留策略。历史、主机信任和隧道不进入交换备份或同步 outbox。

服务器详情取得当前已连接终端的只读引用，按请求创建并释放 exec/SFTP 子通道；关闭详情引用不关闭终端。原页面只在详情可见且应用位于前台时每三秒采样，隐藏和切换后丢弃旧结果。Linux `/proc` 采集脚本沿用固定历史源；不支持的远端明确报错，不用零指标冒充成功。

## 隧道

本地、远端与动态 SOCKS5 隧道各自建立 SSH 路由，复用同一认证/指纹策略。配置加密保存在当前空间，应用重启后等待手动启动。监听仅允许 `127.0.0.1`、`::1` 或 `localhost`，端口 0 自动分配；动态模式仅支持 TCP CONNECT，域名在远端解析。

每个隧道最多 32 个活动或握手中连接，握手有界；流式 pipe 保持背压和半关闭。断网释放已有转发，按指数退避最多十次重新建立监听，不重放数据。状态带代次及递增修订，停止/启动/保存/删除按隧道串行；停止同时释放本地监听与 SSH 连接，远端释放等待 unforward 或底层连接关闭。端口占用、远端拒绝等错误提供中文失败状态。
