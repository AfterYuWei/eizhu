# 补全性能与验证

前端保留输入缓冲、静态命令规格、前缀过滤、缓存和候选展示；回归随桌面 React 工作区运行。缓存绑定会话/服务器、工作目录、请求参数和空间代次，使用大小/过期上限；异步结果必须继续匹配当前输入。生成器错误不阻断静态候选或基本键盘操作。
