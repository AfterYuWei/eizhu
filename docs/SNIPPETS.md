# 命令片段

侧栏“命令片段”用于新建、编辑、删除及管理片段；`Ctrl/Cmd + Shift + S` 打开独立快选器。全局命令面板分别提供“片段管理”和“快速调用片段”。

快选器检索名称、标签、描述和命令内容，忽略大小写，名称匹配优先。空查询优先显示最近成功插入的片段，其余按名称排列；最近使用仅在内存保存最多 20 个片段 ID，关闭浮层后保留，重启或切换工作空间后清空，不进入备份。

上下键选择、回车只插入、Esc 关闭。单行插入保留终端已有输入，不附加执行回车；多行先预览完整内容和目标，预览中 Esc 返回列表。按住回车产生的重复按键不会在焦点回到终端后提交命令。无已连接终端时仍可搜索、复制和进入管理。

目标固定为打开快选器时的终端。断开、重连、关闭或空间切换使本次调用失效，需要重新打开；工具页面不会捕获后台终端。多行插入要求终端启用安全粘贴模式。快选器只提供插入和复制；管理界面保留预览后的明确执行入口。

片段保存在当前工作空间，沿用现有本地保存和完整备份；官方账号同步尚未开放。

