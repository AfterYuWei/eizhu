## 本地数据与行为边界

- 历史、布局、传输和隧道使用账号空间内的 Rust 加密存储，不加入同步队列或云端完整备份；指标仅存内存，账号切换清空。原有服务器、分组、凭据和片段同步/备份范围保留。
- 历史记录只表示可靠识别并提交的命令，不表示远端执行成功。无法可靠识别的提示符、隐藏输入、TUI 和交互认证不采集；旧历史必须显式选择归属。
- 单行片段插入不附加回车。多行先预览，未开启 bracketed paste 时提供复制入口，执行需明确按钮。
- 续传位置由 Rust 检查点确定，恢复核对源文件和已传摘要；不一致拒绝拼接。暂停保留暂存，取消清理暂存，原目标在提交前保留。浏览器源文件丢失后需重新选择并校验。
- 分屏恢复不保存旧输入或缓冲，不自动连接；隧道恢复保持停止，断线旧连接不重放业务数据。动态 SOCKS5 首版只支持 TCP CONNECT，域名交给 SSH 远端解析。
- 停止隧道先结束转发并发送远端取消监听，再断开 SSH。连接中取消使用可取消底层流，等待清理握手任务；认证请求结束通知使旧确认失效。
- 指标沿用原收集器。可见详情三秒采样，最多 120 个样本；隐藏或后台不发起后续采样，已发出的请求按超时结束且不应用旧结果。
