# eizhu 0.6.1

改进 AI 模型管理、SSH 对话和重连体验，更新应用图标。支持 Windows x64、macOS x64/arm64 和 Linux x64。

## 主要更新

- AI 模型管理支持获取上游目录、按名称或模型 ID 搜索，以及批量添加所选模型。可手动添加模型 ID，在模型列表中选择当前模型或移除条目。配置在点击「保存并使用」后生效。
- AI 对话绑定当前 SSH 标签，按主机组织历史。切换标签时恢复各自的对话状态。同一主机可继续已释放的对话，旧版未绑定主机的历史仍可查看。重连后需重新确认远端操作权限。
- 修复 SSH 重连后终端输入和连接状态恢复的问题。SFTP 支持重连后恢复上次浏览的目录。终端链接改为按住 Ctrl 点击打开。
- 改进滚动条、Windows 标题栏拖动区域及独立编辑器标题栏。端口映射使用独立页面。更新应用图标、启动器和网页图标。

## 升级与安装

- 从 0.6.0 正常覆盖升级时，应用继续使用原用户数据目录。供应商 API Key、模型配置和 AI 历史保存在加密的本机数据中，迁移时同时保留数据目录和原设备密钥。
- 安装包未签名，macOS 安装包未公证，建议从 GitHub Releases 下载后手动安装。各平台的构建信息、最终包烟测报告和 SHA-256 校验清单随 Release 提供。
