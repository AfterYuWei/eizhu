# eizhu 0.5.0

完成阶段 0–6 的 Electron 桌面重构，支持 Windows x64、macOS x64/arm64、Linux x64。用户安装应用无需另装 Node.js。

- 全新隔离数据目录、加密本地资料与凭据管理，兼容 `.eizhubackup` / `.xcbackup` 旧备份。
- SSH 终端、跳板/代理、隧道、命令历史与补全。
- SFTP 流式传输、任务恢复、远程编辑器及安全保存。
- 本地版本备份、第三方云备份和恢复预览。
- 受限 IPC、数据库/计算 Worker、退出协调，以及独立 Electron 更新客户端。

这是首个 Electron 正式版本，**请手动下载安装**。使用全新 `eizhu-desktop` 数据目录，不自动查找或迁移旧数据库；旧资料请通过备份预览导入。请先备份已有资料。

四目标均须完成类型、lint、完整回归、固定兼容、架构检查、原生打包与最终安装包 60 秒合成负载烟测后，工作流才会发布。随包提供各目标构建来源、实际烟测 JSON 和 `SHA256SUMS.txt`；烟测报告中的 `unavailable` / `pending` 保持待验含义。

本版本未签名，macOS 未公证；系统安装/覆盖安装、真实系统密钥库、原生交互、真实外部服务、8 小时混合负载及真实签名升级仍待专门验收。Linux 自动化验证 AppImage/X11，deb/rpm 系统安装和 Wayland 待验。未部署独立更新源时请继续手动安装。

官方账号、账号同步及官方云备份继续延期，相关入口返回 `STAGE_NOT_READY`。完整验收范围见仓库 `docs/RELEASE_CHECKLIST.md` 与 `docs/desktop-rebuild/ACCEPTANCE.md`。
