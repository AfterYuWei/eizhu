# eizhu 0.6.2

改进 SSH 与 SFTP 重连体验，修复操作结束后的残留选中样式，并更新 macOS 签名。支持 Windows x64、macOS Intel x64、macOS Apple Silicon arm64 和 Linux x64。

## 主要更新

- 修复菜单、选择器和按钮在点击操作结束后仍保留选中样式的问题，保留键盘焦点提示。收紧侧栏间距和终端边框，隐藏断开连接的服务器状态点。
- 优化首次 SSH 连接。SFTP 断线后可重连，待继续的传输可单独确认恢复。同步替换前可以查看影响，并从同一入口备份。
- macOS 增加本地网络权限说明和系统设置入口，方便排查 SSH 与 SFTP 无法访问局域网的问题。
- macOS 正式包与 Intel 测试包统一使用 Apple Development 证书。构建会校验安装 DMG 和更新 ZIP 内的签名、证书指纹及描述文件。

## 升级与安装

- macOS 首次从旧签名切换时，请退出 eizhu，下载对应架构的 DMG 并覆盖应用。首次启动可能需要 macOS 放行和钥匙串授权。安装包未公证。
- 覆盖安装继续使用原用户数据目录。构建信息、最终包烟测报告、更新元数据和 SHA-256 清单随 Release 提供。
