# eizhu 0.6.0

新增账号条目同步与 AI Agent v2，并改进 SSH 连接一致性、终端、SFTP 和桌面交互。支持 Windows x64、macOS x64/arm64、Linux x64，安装后无需另装 Node.js。

## 主要更新

- 账号与同步：独立账号空间、主密码登录、首次接入预览、加密增量同步及冲突处理工作台，支持服务器、分组、凭据和命令片段。临时断网、超时及服务端故障保留登录会话与本地修改，恢复后重试。
- AI Agent v2：内置多供应商与 Responses、Chat Completions、Anthropic Messages 协议，提供 Codex、Claude Code、DeepSeek Harness 外部 Agent 接入；统一观察、确认、自动权限与工具审批。连接范围跟随已连接 SSH 标签，支持模型候选、上下文设置、本地加密历史、连续回复、执行记录和处理耗时。
- SSH 与终端：连接前核对选择的地址、端口与实际配置，拒绝过期目标；标签及连接状态绑定本次连接信息。取消连接后释放会话并关闭标签，修复 Bash 提示符兼容、重复粘贴，改进补全、目录跟踪、语法高亮和服务器指标。
- SFTP 与编辑器：改进流式传输、任务恢复、目录操作、跨服务器传输与独立编辑器，修复右键删除多选文件及树形目录选中项的问题。
- 桌面界面：统一紧凑中性样式，调整标签、侧栏、设置、连接弹窗和文件面板，保留深浅主题、键盘操作与响应式布局。
- 备份与更新：自动备份生成独立的本地可导入文件，并上传到已启用的第三方云目标；完善 GitHub Releases 的 stable/test 通道及更新资产校验。

## 升级前请阅读

- 请先导出密码加密备份并保存密码。继续兼容 `.eizhubackup` / `.xcbackup` 文件；旧版 Electron 0.5.0 用户建议手动下载安装本版本，旧 Tauri 版不会自动迁移数据库。
- **AI Agent v2 会在每个空间首次打开时一次性清除旧 AI 配置与历史，请重新配置供应商或外部 Agent。** 服务器、凭据、账号与其他业务数据保留；新版 AI 配置和历史仅在本机加密保存，不进入账号同步或备份。
- 官方 AI 需配套部署 `/api/ai/v2` 后端；外部 Agent 需自行安装、配置和登录相应 CLI，Windows 可显式选择原生可执行文件或 `.js` / `.cjs` / `.mjs` 入口。真实模型及 CLI 完整任务仍需在使用环境核验，远端 Windows shell 不在 AI 工具支持范围内。
- 本版本移除旧版本管理与安全快照恢复，改用可导入文件备份；已有云端数据不作清理。官方云备份仍未开放，账号条目同步与文件备份分别管理。

## 验证与已知边界

正式发布工作流要求四目标分别完成类型、lint、完整回归、固定兼容、架构检查、原生打包及最终安装包 60 秒合成负载烟测，并核对版本、提交与源码指纹。实际结果随 Release 提供各目标构建信息、烟测 JSON、更新元数据及 `SHA256SUMS.txt`；报告中的 `unavailable` / `pending` 保持待验含义。

安装包未签名，macOS 未公证，建议手动安装。Linux 自动化覆盖 AppImage/X11，deb/rpm 系统安装及 Wayland 待验。真实系统密钥库、真实外部模型与 CLI、生产服务复验、人工原生交互、8 小时混合负载及真实签名升级仍需专门验收。完整范围见仓库 `docs/RELEASE_CHECKLIST.md`。
