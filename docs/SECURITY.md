# 数据与进程安全

渲染窗口启用 sandbox、contextIsolation 和 webSecurity，禁用 Node 集成；仅加载可信本地应用资源。
main 校验 WebContents、顶层 frame、origin、方法 schema 和上下文；core 再核对空间。未知/未开放方法不能进入业务层。
外链只允许 http(s)，通用文件系统、SQL、原始 IPC 和进程执行能力不向 React 开放。

设备密钥文件采用带版本和保护模式的 envelope。优先系统密钥库；Linux basic_text 视为不可用。
仅首次创建时允许受限文件：Unix 私有目录/0600，Windows 当前用户 ACL。已有密钥损坏、无法解锁或已有数据缺 key 时保持原状并报错。
本机烟测使用独立临时目录及合成密钥，不代表系统密钥库或签名稳定性已在各平台验收。

阶段 2 的领域实体、内联/代理凭据、本地状态、outbox、预览与安全快照均按用途 AAD 加密；全局 UI 偏好及不含正文的审计元数据单独保存。阶段 3 历史、主机信任和隧道配置也按用途加密；阶段 4 传输检查点按用途加密保存，不进入备份或同步 outbox；阶段 5 的备份密码、版本、第三方目标配置及 OAuth 令牌也按用途加密，普通列表只返回元数据；官方账号令牌尚未接入。凭据只在显式查看/复制时返回，不持久化于前端状态；敏感剪贴板由 main 计时，30 秒后仅在内容未变化时清理，退出时亦尝试条件清理。
Buffer 用后尽快覆盖，但 JavaScript 字符串、跨进程克隆和 GC 不具备可靠析构清零保证，不能作超出运行时能力的承诺。
日志有限额、轮换和脱敏，不输出第三方错误对象/请求载荷/凭据；日志与诊断的实际验证边界见 [最终验收矩阵](desktop-rebuild/ACCEPTANCE.md)。

SSH 每跳校验主机指纹，随机确认请求在连接关闭/重连时失效；MFA 不进入历史。补全只接受固定生成器，终端输出通过授权的二进制 MessagePort，等待消费确认后补充额度。隧道仅回环监听并限制并发；实现与测试范围见 [SSH 文档](SSH.md)。

第三方云备份的系统代理/TLS、重定向、条件索引写与 PKCE 回调边界见 [云备份说明](BACKUP_CLOUD.md)。账号第二批已实现认证与会话业务，本轮验证使用本机合成 HTTP 服务，真实后端账号与邮件仍待验。账号网络固定服务端，独立内存 Session，不跟随重定向、不使用 Cookie，认证写请求不复用旧连接。令牌仅在业务层与加密存储中处理，渲染端只收到脱敏状态；刷新响应丢失要求重新登录，旧刷新结果不能覆盖新会话。条目同步仍返回 STAGE_NOT_READY，范围和证据见 [账号闭环交付记录](desktop-rebuild/ACCOUNT_CLOSURE_2026-10-27.md)。

更新方法仅主窗口可调用，来源由构建时 HTTPS 基址固定；拒绝渲染端提供下载路径或 URL。候选令牌与上下文共同限制更新进度/安装，下载摘要错误不能触发安装。更新退出复用未保存确认和备份关闭屏障；主密钥在最终 will-quit 清理，避免安装器同步失败后业务恢复使用已清零密钥。真实签名升级仍待平台验收。
