# 数据与进程安全

渲染窗口启用 sandbox、contextIsolation 和 webSecurity，禁用 Node 集成；仅加载可信本地应用资源。
main 校验 WebContents、顶层 frame、origin、方法 schema 和上下文；core 再核对空间。未知/未开放方法不能进入业务层。
外链只允许 http(s)，通用文件系统、SQL、原始 IPC 和进程执行能力不向 React 开放。

设备密钥文件采用带版本和保护模式的 envelope。优先系统密钥库；Linux basic_text 视为不可用。
仅首次创建时允许受限文件：Unix 私有目录/0600，Windows 当前用户 ACL。已有密钥损坏、无法解锁或已有数据缺 key 时保持原状并报错。
本机烟测使用独立临时目录及合成密钥，不代表系统密钥库或签名稳定性已在各平台验收。

后续凭据、令牌、历史及任务按所属策略加密。凭据只在显式查看/复制时返回，不持久化于前端状态；敏感剪贴板仅在内容未变化时清理。
Buffer 用后尽快覆盖，但 JavaScript 字符串、跨进程克隆和 GC 不具备可靠析构清零保证，不能作超出运行时能力的承诺。
日志有限额、轮换和脱敏，不输出第三方错误对象/请求载荷/凭据；诊断导出与业务日志随后续阶段验收。
