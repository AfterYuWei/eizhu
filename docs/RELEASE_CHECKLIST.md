| 门禁 | 验证及所需证据 | 当前边界 |
|---|---|---|
| 版本/来源 | VERSION、stable/test、提交、构建配置、最终包 SHA-256 和包内输出一致 | 本轮本机记录在阶段 6 delivery.json |
| 四目标 | 当前提交 Windows x64、macOS x64/arm64、Linux x64 最终包全进程树报告 | 本轮仅 macOS x64，其他待验 |
| 支持系统 | Windows 10/11，macOS 13+，Ubuntu 22.04/24.04、Debian 12、受支持 Fedora | 各系统人工实测待验 |
| 安装/卸载 | 干净安装、覆盖安装、路径含中文/空格、数据保留；Linux deb/rpm 真安装 | 本轮 DMG 内容启动；系统安装矩阵待验 |
| 原生桌面 | 按钮/拖动/全屏/缩放/多显示器、IME/TUI、系统拖入拖出、X11/Wayland | 自动化覆盖范围以报告为准；人工待验 |
