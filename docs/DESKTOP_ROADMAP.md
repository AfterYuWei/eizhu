# 桌面客户端完整改造执行记录

更新日期：2026-10-03。本文以用户确认的执行范围为准。

## 交付边界

完整客户端改造分阶段 commit，使用单元测试和静态检查验收。本地不运行完整客户端构建、安装包构建或桌面烟测。admin 镜像构建、部署及服务端测试由用户负责；移动端正式化不进入本轮。运行单元测试需要编译测试目标，回环协议测试需要允许本机监听。

新业务持久化由 Rust 负责，按账号空间隔离。命令历史、布局、传输记录、隧道配置和指标缓存不进入账号同步或云备份；已有服务器、分组、凭据和片段同步保持兼容。

## 固定决策

- 历史默认自动记录，每服务器最多 500 条、30 天；提供关闭、隐私模式、清理和旧数据归属选择。只记录可靠识别的 shell 命令，不记录认证、隐藏输入、TUI 或全部键盘输入。
- SFTP 包含错误详情、重试、暂停、断点续传及目录检查点。后端维护偏移和执行代次，恢复前校验源文件及已传部分，原目标在提交前保留。
- 分屏最多四个窗格，保持终端实例及会话身份；布局本地保存，重启后手动连接。
- 隧道包含本地、远端和动态 SOCKS5 TCP CONNECT；仅回环监听，每隧道最多 32 条并发。使用独立受跟踪 SSH 连接，重启后手动启动。
- 补全改为生成器 ID 和结构化参数；文件候选使用 SFTP。缓存上限每会话 128 项、1 MiB，候选最多 200 项，保留远端 Tab。
- 编辑器使用三份内容比较与手动合并，保存失败保留修改。安全替换能力不足时提供另存入口。
- 指标仅在详情可见时按三秒采样，保留 120 个内存样本。

## 本地历史交付

Rust 新增可重入的 `local_preferences` / `local_history` 表，使用当前空间密钥加密，不写入同步队列。设置页提供开关、保留策略、服务器历史查询、单条删除和空间清理；当前终端可启用会话隐私模式。旧浏览器历史保持待迁移，显式选择服务器后导入，成功后删除旧键。完整备份仍只导出原有四类业务数据。

采集器只接受正常终端缓冲区中可识别提示符后、与本次单行输入一致的回显。隐藏输入、过期重建、多行输入和行首空格不记录；补全关闭不会关闭历史。提示符无法可靠识别时宁可不记录。暂未进行真实 shell、IME 及 TUI 验收。

## 桌面动作交付

命令面板、顶部侧栏/SFTP 按钮与标签按钮复用共享动作入口。新连接显示可搜索的服务器选择器；重连调用实际 IPC 并防重复；SFTP 优先打开当前服务器和工作目录；SSH 命令真正写入剪贴板，不含密码和私钥，路由/选项无法完整表达时明确提示。

快捷键为 Ctrl/Cmd+Shift+K（面板）、T（新连接）、W（关闭）、B（侧栏）、R（重连）、E（SFTP）、C（SSH 命令）、F（终端查找）。输入法组合、Alt 和已有对话框限制拦截上下文，原始远端 Ctrl 键保持透传。终端增加本地缓冲区查找入口，关闭查找恢复终端焦点。实际系统焦点及快捷键仍待原生验收。

## 片段交付

桌面新增片段入口与 Ctrl/Cmd+Shift+S，支持名称/标签/内容搜索、新建、编辑和二次确认删除，沿用既有 Rust CRUD、同步与备份。单行直接插入但不附加回车，多行先预览。远端未启用 bracketed paste 时只提供复制入口；执行使用明确按钮，粘贴和提交封装在同一个输入事件中。

预览锁定目标终端、连接身份和空间代次，切换空间或连接后拒绝旧预览。未增加变量模板或批量执行。原生终端的 bracketed paste 行为仍需真实 shell 验收。

## 编辑器关闭协调

保留原有主窗口/编辑器关闭保护，将桌面窗口创建与生命周期协调提取到平台适配器，IPC 只转发。标签、窗口、退出和账号切换使用共用脏标签检查；保存后再次检查全部目标标签，保存期间继续编辑或任一保存失败都不放行。

账号登录、注册或退出在发送账号 IPC 前请求编辑器确认。确认绑定请求 ID、串行处理；保存/放弃后关闭旧编辑器再放行，取消保持原账号及旧空间。编辑器尚未就绪时要求稍后重试，窗口销毁取消挂起确认。

## 编辑器冲突与保存

冲突保留“打开时、本地、最新远端”三份内容，提供手动合并结果；应用合并只更新编辑缓冲及待核对的远端令牌，不自动保存。取消比较不改变本地内容或令牌。保存期间新编辑仍保持脏状态；旧空间与过期读取结果被丢弃。独立编辑器在准备 IPC 桥接前读取空间代次。

保存使用同目录私有临时文件，完整写入并刷新后重新核对修改时间及 SHA-256 内容摘要。本机通过原子替换，远端协商 OpenSSH posix-rename 扩展；缺少能力或目标是符号链接时返回另存提示。替换前保留原目标，失败清理本次临时文件；Unix/远端权限及所有者保留。另存只创建新目标，拒绝覆盖已有文件。真实服务端扩展、Windows/macOS 文件权限与系统故障仍待原生验收。

## 同步与备份交付

同步队列显示当前条目名称，错误代码持久化并在成功确认后清除。登录、解锁、联网、配额和重试提供独立入口；条目徽标打开对应同步处理页，分组、凭据和跳板冲突可跳转依赖。沿用既有协议及修订保护，本地保存与云端确认分别显示。

完整恢复预览显示由 Rust 确定的本地版本、云端目标/对象、安全快照或旧账号来源，及每类条目的新增、变更、相同、替换时移除数量。预览在隔离数据库校验，仅保存加密且有时效的确认令牌；取消不应用业务数据。旧账号预览改为只读取最新版本，不再隐式复制云端对象。同步与备份提供白名单脱敏诊断，排除名称、正文、凭据、原始错误和目标配置。

## SFTP 任务存储基础

新增空间内加密 `local_transfers` / `local_transfer_files` / `local_transfer_blocks`，保存完整任务描述、分块摘要、已确认偏移和执行代次。增量迁移可重入，不写入同步 outbox。进程重启把未结束任务标为待手动恢复，不自动重放；数据库拒绝旧代次覆盖新检查点。任务列表可读入历史记录。恢复引擎与界面已接入暂停、继续、重试 IPC。每个确认块的偏移、摘要与任务状态在同一事务保存；重复上传块校验后幂等返回。暂停等待块完成并释放文件句柄与并发许可，取消清理受控暂存；清理失败保留待清理记录。

恢复核对源大小、时间和源/暂存分块摘要；不一致停止拼接。目标在提交前重新核对，原子替换能力不足时拒绝覆盖。提交意图持久化后再替换，重启可识别已经提交的文件，避免重复覆盖。目录逐文件恢复；归档先保存本地检查点再生成归档，中断后重新生成。浏览器文件恢复需要重新选择并校验原文件，后端确定偏移和新执行代次。进度同状态每 200ms 最多发送一次，确认检查点仍逐块落盘。

引擎测试覆盖重启、源文件同大小同时间改变、暂存损坏、空文件/中文目录、归档、磁盘不足、网络错误、重复块、提交中断、排队时暂停与许可释放。真实 SSH/SFTP 服务端及桌面保存对话框仍待验收。

## SFTP 队列交付

队列读取当前空间的持久任务，在尚未连接服务器时也显示待恢复记录；订阅全部会话任务，忽略旧空间和旧执行代次进度。暂停、继续、重试、确认重新开始、取消清理、下载保存及错误代码/详情均有实际入口。上传中断保留检查点，不自动取消；恢复浏览器文件会打开文件选择器，逐块读取并核对已传摘要，不读取整个文件。无需浏览器文件的路径任务由 Rust 重开。API/事件/合并测试覆盖多个会话、旧空间响应、迟到进度、重新开始偏移归零、文件身份不符和提交后不重复发送。

## 补全生成器契约

前后端同提交切换为生成器 ID、结构化参数和 cwd；Rust 拒绝未知生成器、多余参数、非法 namespace 和控制字符，执行固定模板。目录候选通过 SFTP 结构化名称与类型返回，支持空格、引号、中文和真实后缀，不解析 ls 文本。每次路径响应最多 200 项，远端目录读取和命令有超时，命令输出最多 1 MiB。静态候选先显示，动态结果随后合并；Tab 保持远端 shell 控制键。进程内 SFTP 测试验证特殊文件名与目录句柄关闭。缓存按空间、服务器、连接状态代次、cwd 和生成器隔离，LRU 上限 128 项 / 1 MiB，单次候选最多 200 项。处理 `--`、等号值、已用选项、可重复选项和互斥选项；合并顺序稳定，静态候选优先。动态查询与 PTY I/O 同时轮询，单会话最多一个查询，退出时随终端任务结束，不阻塞输入。过期、旧连接、旧输入与旧 cwd 响应不应用。补全缓冲修正滚动后光标行读取。

## 四窗格交付

布局采用最多四叶的分割树，支持向右/向下分屏、鼠标与键盘比例调整、焦点循环、最大化/还原和合并。所有终端按标签 ID 固定挂载在同一层，只改变绝对位置和可见性；可见窗格均观察尺寸，只有聚焦窗格发送输入。新窗格打开服务器选择，关闭窗格关闭对应标签；合并保留其他标签和 SSH 连接。

布局与服务器引用通过 Rust 加密本地存储，账号切换取消旧空间保存/恢复；恢复后均为停止状态，服务器需手动连接，不保存缓冲或旧输入。快捷键 Ctrl/Cmd+Shift+H/J（分屏）、N/P（焦点）、M（最大化）、G（合并），命令面板和工具条复用动作注册表。测试核对四窗格上限、比例与焦点、合并/关闭会话数量、节点和缓冲保留、损坏数据及旧空间恢复；系统焦点、真实 xterm/IME/TUI 仍待原生验收。

## 发布配置

桌面打包需要通过环境注入 `EIZHU_ACCOUNT_SERVER`。GitHub 仓库 Variables 分别配置 `EIZHU_ACCOUNT_SERVER_TEST` 和 `EIZHU_ACCOUNT_SERVER_STABLE`，CI 按通道严格选择，无跨通道回退。打包入口拒绝缺失、占位、非 HTTPS、携带认证/查询/片段的地址；普通开发和单元测试不要求账号地址。

桌面 stable/test 发布调用同一份可复用 Quality，构建依赖该提交全部检查成功；远端 CI 既有桌面烟测保留。本轮仅本地分阶段提交，推送与发布另行安排。

## 本地 SSH 转发交付

新增空间内加密隧道配置、CRUD、启动/停止及带执行代次和修订号的状态事件；配置不进入同步或完整备份，重启保持停止。每条隧道使用独立 SSH 路由，复用代理、跳板、凭据和主机指纹流程。键盘交互认证使用终端和隧道共用的请求协调器，超时、取消或连接 future 结束均通知界面关闭失效请求；界面按请求 ID 排队确认。

本地监听仅允许回环 IPv4/IPv6，支持自动端口和域名目标；32 条连接上限，保留 TCP 半关闭。停止、空间切换和退出取消并等待转发任务清理，断线沿用退避规则至多重试十次，等待连接期间丢弃业务连接。实际 SSH/TCP 回环测试覆盖中文数据往返、半关闭、占用端口、并发上限、停止释放和重启不自动启动。远端转发与 SOCKS5 在后续独立提交完成。

## 远端 SSH 转发交付

增加远端回环监听请求、自动端口、接收通道和取消监听请求。回传通道仅接受本条独立 SSH 连接已注册的回环地址与端口；队列和活动转发共享 32 个许可，拒绝未经注册的地址与超限连接。目标由本机访问，支持域名、IPv4 和 IPv6。停止先拒绝新通道并等待全部转发结束，再发送取消监听，随后断开并等待 SSH 与跳板任务结束。请求拒绝、占用端口和连接失败显示具名错误，可停止或重试。

进程内 SSH 回环测试覆盖远端数据往返、半关闭、自动端口、请求拒绝、非法回传通道、32 条连接上限、取消请求和端口释放；真实服务器的转发策略及 GatewayPorts 行为待验收。

## 动态 SOCKS5 交付

动态隧道使用本地回环监听及独立 SSH 路由，支持 SOCKS5 无认证 TCP CONNECT、IPv4、IPv6 与域名，域名不在本机解析。逐字段读取可处理分片握手；协议、握手大小与超时有界，拒绝 BIND、UDP、不支持的认证方式、非法地址及零目标端口，返回协议错误或目标连接失败。握手中的连接也计入 32 个并发许可，停止会取消未完成握手并等待释放监听。

协议单元测试验证分片及非法请求；实际 SSH 测试以仅测试服务端识别的域名验证远端解析、中文数据往返、半关闭、目标拒绝、握手取消、32 条连接上限及端口释放。三类隧道的真实代理、跳板、交互认证和系统端口行为待原生验收。

## 指标与最终回归交付

沿用现有 CPU、内存、磁盘和网络指标，新增两组短时趋势。每主机内存保留最近 120 个六字段样本，重复/过期时间戳不更新，隐藏期间用时间间隙表示停采，不伪造连续数据。详情隐藏、侧栏折叠或应用后台时停止后续轮询，仍为三秒周期；同一空间/会话请求去重，旧会话和旧空间结果不应用。Rust 指标命令增加 15 秒超时，不新增操作系统收集器。关闭期间迟到的管理连接被清理，账号切换不复活旧详情。

最终回归加固隧道握手的取消边界：底层流可取消，停止/连接失败等待流清理；认证取消与网络关闭分开，远端转发先发送取消监听再关闭 SSH。真实回环测试覆盖挂起握手及主机指纹确认中停止、失效请求拒绝，并再次验证三类转发的释放。
