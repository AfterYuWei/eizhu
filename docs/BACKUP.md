# 备份与恢复契约

备份业务在阶段 2 实现，云目标/调度在阶段 5 实现。当前基础工程不提供生产导入器或导出器。
固定旧实现样本及独立 Node 字节校验已保留，见 [精确格式与来源](desktop-rebuild/COMPATIBILITY.md)。

继续导出 `.eizhubackup` v1，接受 `.eizhubackup` 与 `.xcbackup`，保留 none/plain/encrypted、Argon2id 参数、UTF-8 密码、AES-256-GCM、AAD、Base64 与 nonce/ciphertext/tag 顺序。
分组、服务器、凭据、片段保持 ID、排序和关联；重新生成 ID 必须同步修正关联。预览隔离，应用重新核对空间与修订，安全快照、合并/替换及事务失败回滚必须验收。
不读取旧数据库、key、设置或任务来获得兼容性。旧备份不包含 UI 设置、历史、未完成传输和云目标配置，不能承诺恢复这些内容。

验收必须使用冻结旧样本，覆盖中文密码、代理密码、受口令保护的真实 OpenSSH 私钥、依赖重映射、错误密码/损坏文件/限制及回滚。
XControl 三模式构造样本经旧读取器验证；另有原历史空样本。不能把构造样本标为来自历史用户设备，也不能只以新实现自导出/自导入证明兼容。
